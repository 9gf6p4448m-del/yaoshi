## 2. 資料與介面約定

```js
const NIGHTWALK=[{
  n:1, title:"破廟逢青面", boss:"qingmian",
  rules:{chains:false, destiny:false},          // 第 2 章 chains:true；第 3 章兩者 true
  teach:["…","…"],                              // 本章新規則 2–4 條
  intro:["…","…","…"],                          // 引言 3–5 句
  feud:{open:["…"], bossLose:["…"], bossWin:["…"]},
  scroll:{title:"…", text:"…"},                 // 殘卷 150–300 字
}, …];
```

- 進入點：`startEntry('nightwalk')` 開章節選單；章節局 `S.mode` 仍是 `"solo"`，另加 `S.chapter`（章號）。常規局 `S` 不出現 `chapter`／`chainsOff` 欄位。
- 主角入座：章節局才走的新分支；常規局 `rosterSeats` 的亂數消耗與輸出不變。
- 連鎖關閉：`S.chainsOff=true` 時所有連鎖效果、AI 連鎖加值、連鎖提示／狀態介面都不出現。**先用 grep 數出 `CHAINS`／`activeChains`／`chainsCompletedBy`／`requirements` 的全部引用點（分母 N），逐一決定是否要擋並記錄**（`02 §6.1` 第 7 條）。
- 天命關閉：`destinyEffectMode="off"`、`destinyAiChase=false`，且天命密函／徽章等介面不出現。
- 存檔：`localStorage` 讀寫全包 try/catch；壞 JSON、`v` 不是 1、非陣列一律當空進度，不丟例外。
- 版本：`RELEASE_VERSION`／`VERSION`／`VERSION_NOTE`（`index.html:2388–2390`）與 `tests/ui-hierarchy.test.mjs:25` 同步改成 `0.58.0`。
