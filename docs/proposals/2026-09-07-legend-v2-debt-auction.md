# 提案：請神 2.0「神債暗標」（2026-09-07，使用者裁定採用）

## 一、為什麼改
- 使用者真機試玩 v0.44：「請神成功的代價只有燒香的壽命，玩家都會捨棄法寶去每回合賭 3」。
- 數據早就顯示：傳說實作卷 L4 六策略「每夜燒滿」勝率 33.7%、splitter 23.0%、「從不燒香」15.8%（`docs/experiments/2026-09-06-legend3-impl-report.md`）；L1″ 狀態①「開局燒滿 3 對四家皆嚴格優勢」一直紅。
- 根因：**天井**（h≥12 必請）＋骰子讓請神變成獨自進行的存錢計畫，與三支柱（深度在拍賣桌／壽命自平衡／隨機由對手設計）都無關。

## 二、規則（取代 v0.43～0.44 的 h/(h+K) 擲骰＋天井）
1. **請神夜**：固定第 4、7、10 夜（`CFG.SHRINE_NIGHTS=[4,7,10]`）。**哪一尊落在哪一夜每局開局用 `S.rng` 洗牌並公開**（神龕卡顯示「第 N 夜請」與倒數）。
2. **燒香**：每夜開標前密封燒 0～`INC_MAX`(3) 壽命到任一開放的龕（不變），累計為該龕的 h，四家 h 公開（不變）。燒香上限仍＝壽命−1。
3. **結算**：到該龕的請神夜，開標後 **h 最高者請走**；同分依「本夜風位起順時針」（沿用 `shrineRollOrder` 的洗牌？→ **不**：同分改依風位順序，決定性、可讀；v0.44 的洗牌只用於擲骰時代，本卷移除擲骰即一併移除洗牌與 `INC_K`／`INC_PITY`）。沒有任何人燒過香（h 全 0）的龕**回天**（該尊本局不出現）。
4. **落空者**：階段獎勵照現行（h 依區間退香灰壽命／小法寶），區間改以「本龕最高 h」的比例定義（h≥ 1/3 最高值退 ⌈h/3⌉，≥2/3 退 ⌈h/2⌉＋小法寶），不再用 P。
5. **一人一尊**：請到一尊後，其餘龕不再收此人的香（封籤 UI 直接鎖）。
6. **供奉（神債）**：持有傳說者每夜末付 `INC_TITHE`(1) 壽命；付不出（壽命 ≤1）則傳說回天、從袋中移除，該龕**不**重開。回顧與戰況 log 要記「供奉 −1」與「回天」。**互動口徑（使用者 2026-09-07 問「要不要跳出供奉與否」→ 裁丙）**：平常自動扣、不跳窗；袋子面板傳說旁常駐「送神回天」鈕（任何一夜可主動放手，當夜起不再供奉、龕不重開）；只有「付完供奉壽命會 ≤`TITHE_WARN`(2)」那一夜跳一次提示「壽命危急，繼續供奉？」（要／送神回天），同一尊只提示一次；AI 的放手規則走同一條門檻。
7. **AI 啟發式**：改為「估值 − 已投入 − 追平所需 ≥ 0 才追」的簡單追價模型（不重抄引擎；只讀公開 h 與自己壽命），並保留 `INC_AI` 個性參數。
8. **UI**：神龕卡改顯示「第 N 夜請・倒數 M 夜・你 h／領先 X h」，四家香火改一行；機率表拿掉；規則頁改口徑。**版面同時搬**：北家回頂端正中，三龕整排放進中央面板法寶卡上方；盯上宣告說明第二夜起收成一行；修橫式 19px 溢出；教學三卡加「請神」一頁。
9. 開關：`CFG.LEGEND_ON` 沿用（`?legend=0` 關）；沒有 1.0／2.0 並存旗標，2.0 直接取代。

10. **（使用者 2026-09-07 裁定採用）傳說共鳴**：現況傳說帶 `f`，`facCount`（`index.html:2136`）把它算成該系 1 件 → 只多 1 件共鳴數＋自己的招式，沒有額外強化同系法寶。使用者問「請神會不會強化自己那個陣營的寶物」。➡️ 建議加「**傳說共鳴**」：傳說在共鳴計算視為 **2 件**（沿用雷女之火／五營旗既有的 `onFacCount +1` 機制，不開新 hook），讓「我在湊哪一系」直接決定「我該搶哪一尊」，而三龕的請神夜與尊→夜洗牌又是公開的——對手看你燒哪一龕就讀得出你的構築（支柱一＋讀人）。代價：共鳴 M1 每拍每隻 hp +min(3, 件數−1)，多 1 件最多 +1 hp；上限 CAP 3 不動；閘門 R2′／R3 重跑。不建議做「傳說直接給同系全體 atk」那種光環——那會疊在共鳴上變成第二套加成，且與 ART／招式表的單一事實來源相衝。

11. **（使用者裁定採用）袋子「部隊預覽」＋招式顯示**：袋子面板與市集法寶卡每件法寶顯示 隻數／atk／hp／出手拍／招式名＋一句效果（`TRAITS` 表）（用引擎同一支 `buildArmy` 展開，不另寫規則），最上方一行「總隻數・總攻・總血・共鳴 hp」；「力」數字保留但降為次要（它是舊公式，紙紮夜戰不用它）。動機：使用者試玩持兩尊仍 12/12 全燒，看不出「為什麼輸」——袋子全是 atk 0 的作祟型與護法。

## 三、預期與風險
- 「每夜燒滿」不再是優勢：追價只有在領先者附近才有意義；燒下去不退（全員付費）讓過度追價自毀（支柱二）。
- 風險：AI 桌變成消耗戰（三家互追到死）→ 用閘門守：請神夜前三家平均燒掉的壽命、局長中位、落空者平均損失。
- 風險：三尊全部回天（沒人燒）→ 活性閘門守（≥80% 的局至少請走一尊）。

## 四、閘門（寫進凍結檔）
G0 kill switch 雙向；G1 優勢策略：每夜燒滿 vs splitter ≤ +5pp、從不燒香 ≥ splitter −8pp；G2 活性：≥80% 局至少一尊被請走、供奉回天 1～20%；G3 節奏：局長中位 10～12 夜；G4 消耗戰：請神夜前三家平均燒香 ≤ 9 壽命、落空者平均淨損 ≤ 6；G5 單元測試（同分風位、一人一尊、供奉回天、回天不重開、h 全 0 回天）＋舊版紅；G6 Playwright（請走、回天、落空獎勵各至少一次、0 error、橫式溢出 0、直式蓋板不變）；G7 版面截圖人眼（北家正中、三龕在卡上方、10v10 對決不受影響）。
