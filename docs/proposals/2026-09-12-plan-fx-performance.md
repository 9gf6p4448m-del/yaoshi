# 計畫：招式演出卷（2026-09-12，取代招式可辨性卷批 1–3）

> 讀者：製作人與接手的 agent。前身：`2026-09-11-plan-fx-legibility.md`（可辨性卷）。本卷是方向重定，不是新功能。

## 0. 一句話
**0.55 批 0 的「徽記剪影」手段做錯了：目標（招式一眼能辨）不變，手段改成「本體動作＋小型紙紮道具＋受招方反應」，先做一支原型讓製作人挑，挑定再鋪 27 支。**

## 1. 為什麼重定（證據）
1. 兩輪盲讀：批 0 六讀者只認出千里眼銅鈴；刀印帽回修後三對六讀者 12 格 0/3（`2026-09-12-emblem-fix-report.md` §9）。六位讀者不約而同說 16 張只剩「金鈴／藍刀劍／紅雙尖角／紅階梯塊」四個族群。
2. 製作人親看材料（`…-emblem-fix-evidence/sheets-after/a06.png`、`…-b0-evidence/sheets-after/a11.png`）：純色無光照 billboard 貼在有描邊光影的紙紮模型上，像剪貼畫，尺寸比角色大，出現消失沒有紙紮質感。
3. 結構性原因：可辨性計畫把「讀者能說出法寶名稱」當主要資訊，於是要一個 logo；但畫面裡已有那件法寶的 3D 本體（虎爺印＝那隻虎），logo 是第二份、風格不合的身分載體。

## 2. 目標重定
招式可辨 ＝ 觀眾一眼看出 **(a) 誰對誰做了什麼**（傷害／護盾／偷取／詛咒／群體）**(b) 哪一系**（三系語彙沿用 `2026-09-11-plan-fx-legibility.md` §7 的顏色與材質）**(c) 法寶身分為次要**，由 3D 本體＋拍賣桌熟悉度承擔。

## 3. 手段規範
- 每支招＝**本體動作**（既有節點做前傾／彈跳／張口／自割，沒骨骼就整體位移＋squash-stretch）＋**小型紙紮道具**（印文、紙血條、紅帽、紙錢……有厚度＋墨線描邊＋輕微翹曲）＋**受招方反應**（壓扁／抖動／後退／迷途打轉）。
- 禁：純色無光照 billboard 當主視覺；道具尺寸超過施招本體高的 1/2；與本體動作無連動的懸浮圖示。
- 徽記剪影（`emblems.js`）降級為「受招方身上的小印記」或不再使用；`vocab.js` 三系語彙表、`PW_FX.TRAIT_MS_BY_TIER`、phase gate、N11/N12 尺寸防線、L10 治具全部沿用。
- tier 1 短版 260ms 保住辨識元素（本體動作＋受招反應至少各一拍）。

## 4. 流程（品味迴圈）
1. **原型**：虎爺印一支、三版（A 撲咬為主／B 印為主／C 香火為主），每版 6 幀 sheet＋GIF／WebM，走 `threejs-visual-loop` 自評兩輪 → 製作人挑。
2. **語彙定稿**：依挑定版把「本體動作／道具／反應」三件寫成三系語彙（每系各一段），寫進 ART_BIBLE §10 取代徽記段。
3. **鋪 27 支**：三批（祖靈 9／香火 9／陰氣 9），每批 P0–P8 閘門；每批合併前製作人看 sheet。
4. 三尊大招（tier 3）不在本卷。

## 5. 閘門 P0–P8（凍結；數字沿用可辨性卷同名閘門，改的只有 P4 的題目）
- P0 等價：`trace-eq` 對基準逐位元組相等（＝L5）。
- P1 一招一組「動作＋道具＋反應」，登記表可機械檢查（＝L1 改物件）。
- P2 phase gate 機械判（＝L2）。
- P3 對比：道具在暗紅桌面／紫夜空上的 ΔE 與面積，門檻沿用 L3（0.8%／ΔE）；量測位置 844×390@2x、bloom 0.7、seed 7。
- **P4 盲讀（主閘門，改題）**：三對 fresh 讀者、同材料管線（`blindread-sheet.mjs`）。每格三題：Q1「這招在做什麼」（五選一：打／護／偷／咒／群體）、Q2「打到哪一方」、Q3「哪一系」；通過＝三對中 ≥2 對兩位皆 Q1–Q3 全對。法寶名稱改為第四題只記錄不判。P4-pre 材料鑑別力沿用修訂四後的對照組。
- P5 短版原生合身（＝L6）、P6 短版品質下限（＝L7）、P7 效能（＝L8：fps 比值 ≥0.95、draw call 絕對 ≤1000）、P8 零錯＋規則測試全綠（＝L9）。
