## 雲端環境：避免又卡在 Windows 路徑

這是靜態 HTML/JS 專案，不需要本機秘密檔。不要複製任何憑證。
Node 工具最低版本依 Playwright package 為 >=20；本機實裝 Playwright 1.62.1、工具 Three 0.180.0。
遊戲 importmap Three 固定 0.158.0，不因搬環境而升級。

在 repository root 建立未追蹤工具依賴（原 tools/anyCreature 不進 Git）：

```bash
mkdir -p tools/anyCreature
npm install --prefix tools/anyCreature --no-audit --no-fund playwright@1.62.1 three@0.180.0
cd tools/anyCreature
npx playwright install --with-deps chromium
cd ../..
python -m pip install Pillow
git worktree add --detach ../base592 86e46763
ln -s "$(pwd)/tools" ../base592/tools
```

若環境 Python 命令是 python3，使用 python3；缺系統安裝權限時明報，不以跳過瀏覽器測試充作通過。
兩張示意乙與 NOTES 已搬入 `cloud-reference/`；判定器使用卷內既有 `mirror/b-west.png`，不要替換判準圖。
`run-d.sh` 是 Windows 腳本：第 5–7 行有 /c/Users 路徑，suite 段有 PowerShell junction；**不能直接在 Linux 執行原腳本**。
雲端續作時另建環境用 runner，保留全部步驟、矩陣與判定器；root 用 repo 路徑、BASE 用 ../base592、MOCK 用卷內 cloud-reference，junction 改 symlink。
Python 拼圖工具只找 Windows 字型，Linux 需讓 font loader 使用已安裝 CJK 字型，避免簽收圖中文字缺字；只改工具環境適配，不改產品文字。
全套需隔離 CRLF 工作樹：既有 l1-destiny-focus 有 CRLF 錨點；以 `git -c core.autocrlf=true worktree add --detach <新suite目錄> HEAD` 取出，再檢查 index.html 換行及接入 tools symlink。
保留 LF 下假紅紀錄並註明環境原因；不能改測試來掩蓋。上述 Linux bootstrap／runner／字型適配**尚未在雲端實跑**。
