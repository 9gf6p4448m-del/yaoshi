依 `docs/proposals/2026-09-12-roadmap-v2-progress.md` 的既定順序，為既有賽局加入三種純演出的高光轉場：誅心、借刀、命懸一線；不得改變規則、RNG、模擬 trace 或 3D 預算。

- `48f644c feat: add highlight cut overlays` 已在本地 `main` 提交，尚未推送；`main...origin/main` 為 ahead 2（`1616998` RED 測試、`48f644c`功能）。
- `index.html` 以 `CUTS` 表定義三種一次性轉場，狀態放在 `WeakMap`，不寫入 `S`：

  - `因果・斃命`：本夜毒標的目標死亡。
  - `命懸一線・破曉`：冠軍曾降至 5 壽命以下。
- 畫面是 `cutOverlay` DOM 疊層，不新增 3D mesh、render pass 或 draw call；`prefers-reduced-motion` 時不用動態動畫。
