## 真天命量測：能說與不能說

六臂為 `ordinary/original/candidate × AI 追天命 off/on`，每臂 10,000 同種子、同私函配對局；事前契約與門檻見 [驗收文件](../experiments/2026-09-23-destiny/acceptance.md)。在凍結的座位零策略下，真版原案相對普通版的全局勝差：AI 追件關閉時 `+0.33pp`（配對 95% 區間 `+0.12..+0.54`），開啟時 `+0.04pp`（`−0.19..+0.27`）。削峰候選分別為 `+0.21pp`（`+0.02..+0.41`）與 `0.00pp`（`−0.22..+0.22`）。四個比較均落在事前全局 `−2..+5pp` 安全帶，真效果事件並非零，局長 P90 均為 12 夜。這表示**全局沒有測出超過上限的座位零勝率偏移**，不表示每一條真鏈都已帶來規定的 `+3..+10pp` 覺醒收益。

普通 AI 關閉時 10,000 局有 `4,257` 局至少一席覺醒；AI 追件開啟時 `4,871` 局。這是座位零追件策略下的樣本，不是真人自然率；舊無追件代理的 `122/600`（20.3%）是另一策略與樣本。六鏈關閉 AI 時各有 769..829 次四席覺醒。後續已完成[同檢查點焦點席正式比較](../experiments/2026-09-23-destiny/focus-report.md)：10,000 種子、4,886 個覺醒點，在普通狀態與兩支 RNG 完全一致後才啟用焦點真效果。水陸、千眼、雙虎、血祭原案與候選均未達事前最低 +3pp 有益線，判 fail；神王與長明區間跨線，判 incomplete。這推翻了只憑全局安全帶就可稱六鏈已平衡的解讀。

真版事件頻率有明顯不對稱：無 AI 追件原案長明盾 `4,468` 次，候選 `1,688` 次；真神王夜戰事件僅 `72` 次。次數不等於實際吸收傷害、戰局翻轉或玩家讀懂次數。千眼策略在普通基準臂確有 `15,859` 次呼叫、`1,681` 次第四件可見、`1,421` 次既有第二高標可揭、`969` 次與盲策略決策不同，未默默退化成「有 UI 沒策略」。正式摘要在 `scratchpad/destiny-formal-v1/summary.json`，含私函的 raw 只留忽略版控目錄；對外公開數值無法單靠摘要獨立重算。

### 千眼知情策略補充

另依事前契約以 seeds `20001..30000` 跑 `eyes-informed-v1`、增量盲對照與千眼效果歸零三臂，各 10,000 局。知情策略在 **18.69%** 對局至少有一次標單不同，合計在 93,581 次呼叫中改變 5,813 次決策；但座位 0 對盲對照配對勝率差 **−0.18pp**，95% seed bootstrap 區間 **−0.44..+0.08pp**，局長差也近零。這表示策略確實消費資訊，未顯示本啟發式在固定 AI 桌提升勝率；不是「千眼機制無價值」的證明，也不能外推真人。持有者條件差仍非因果，zero 臂會把全桌千眼效果一併關掉。正式千眼 H9 維持 `incomplete`。完整方法、分母、hash 和 UI 建議見[知情策略補充報告](../experiments/2026-09-24-eyes-informed-supplement/report.md)。

畫面覆核支持先優化資訊層：覺醒公告用一行摘要說明「兩件材料 → 本鏈一項效果」，詳細內容留在可回訪私函；手機私函標出還可向下閱讀，並提高返回控制的可見度；千眼以小徽章指出額外第四件，清楚分開預告與前夜已揭價格。這些是待驗證的呈現建議，尚未改 UI 或數值。真人冷讀方案與空白記分表見[事前方案](../experiments/2026-09-24-eyes-informed-supplement/preregister.md#真人冷讀盲讀方案)及[主持記分表](../experiments/2026-09-24-eyes-informed-supplement/blindread-scorecard.md)；至少五位未接觸本卷的玩家尚未實測。

### 發現：事件夜的盯印資訊時序不對稱

現行程式在 `beginRoundCore` 先呼叫 `drawMarks()`，再進入事件輸入；headless 策略迴圈也先 `drawMarks()` 再 `runEventPhaseHeadless()`。但真人的 `showMarkUI()` 是 `startBidUI()` 遇到未盯席位才呼叫，所以事件夜真人先看完整開盅結果、才選盯印，AI 已在開盅前選好。瘟王可能改變袋物，其他事件可能改變各席壽命；因此兩方的盯印可依不同狀態做決定。這個時序差異已做[10,000 組配對診斷](../experiments/2026-09-24-mark-timing/report.md)：首事件 9,999/9,999 配對一致，AI 事件後標記有 1,110/9,999 局至少一席改標；固定座位 0 策略的配對勝率差 −0.06pp（95% 區間 −0.30..+0.18）。時序會改變部分 AI 盯印決策，但目前不能判定勝率方向或真人公平性，不能直接改時序。

最佳保守候選是先保留現行時序和效果數值。真人盲讀／實測若確認玩家不懂為何事件後才盯印，再開「所有存活席位事件後標記」獨立候選；同時固定策略、記標記變更率、費用／避標與勝率區間，將 keyed-RNG 隔離條件和非真人策略限制寫明。原始依據位於 `index.html` 的 `beginRoundCore`／`startBidUI` 與 `playPolicyGame`；量測仍未修改產品檔。

放血治具將可與未封標草稿交錯的 UI 輸入正規化為放血步驟後再交複合標單；這只足以驗合法動作和壽命轉移，不能證明每一種草稿點擊順序都屬同一資訊集合。請神治具只覆蓋真人得主選尊，不覆蓋自動戰鬥、供奉、回天或終局。全遊戲仍 `sixOfFour=incomplete`、`solverStatus=not-run`、`releaseEligible=false`；`index.html`、平衡值、H9 門檻都未變。
