# 妖市六連鎖與天命密函：接手審視與 Premortem

日期：2026-09-23。檢查版本：`2eb164d`／`v0.57.40`，工作樹 `feat/l1-water-chain`。本卷是設計與實作審查，不是 `v0.57.41` 的實作或放行。

**後續校正**：下文把 `pwHaunt`／`pwFeed` 的「整側存活即可觸發」稱為既有漏洞，語氣過度確定。[2026-09-07 原驗收](../experiments/2026-09-07-acceptance-duel-desync.md)僅要求整側全滅時停止，沒有裁定施術隊死亡就必須停止。普通版維持整側存活語意；「來源隊須存活」只列為真版候選的平衡比較，不以此逕改既有戰果。

## 1. Antigravity 實際完成了什麼

- `227f239` 與 `2eb164d` 把既有三組連鎖調整並補成六組**普通連鎖**，含拍賣、夜戰、UI 提示與單元測試；這些提交早於後續天命 Teamwork 任務。
- 後續 Teamwork 任務只留下 `.agents/ORIGINAL_REQUEST.md`、briefing、dispatch 等協作檔。天命抽籤、覺醒、六組真效果、專屬測試及 `v0.57.41` 均未進產品碼。原始日誌以 `RESOURCE_EXHAUSTED` 結束。
- Antigravity 的 `walkthrough.md` 稱「44 項全覆蓋」，實際上 44 項只是指定六檔回歸。擴跑 48 檔（排除約 13 分鐘的 `sfx-wiring` 和已知失敗的 `release-update`）結果為 **197/203 通過、6 失敗**：3 項卡在測試治具缺 `chainHintHTML`，1 項因新 chain hook 函式使 `structuredClone` 失敗，2 項因種子 1/2 的舊因果紀錄預期過期。`release-update` 另有 **0/2 通過**，根因是 `VERSION=0.57.39`、`RELEASE_VERSION=0.57.40`，首頁標題與更新提示錯版。前六項不可直接當成產品玩法失敗，也不能視為全綠。
- Antigravity 說送王船可吸收神王開場狙擊；實作裡神弓在第 1 拍直接扣 `hp`，送王船的 4 點吸收在第 2 拍才設置。這個「生剋」未成立。

### 可玩到的機率（離線代理，不是新功能驗收）

現有規則跑 seeds 1..600；以獨立種子讓四席各自等機率、有放回抽一條天命，再查真實袋子歷史：**122/600 局（20.3%）至少一席完成自己的天命**，共 126 次成型；其中 63 次在第 1–6 夜，63 次在第 7–12 夜。這尚未加入真版效果與 AI 的天命估值 +2，也沒有玩家主動追件，不能當正式機率；但它顯示「每局都看得到覺醒」目前沒有證據。若天命只是稀有驚喜，20% 可以是刻意設計；若它是改版主角，需另做可選命函／追件介面與實測。

## 4. 失敗預演：若照原案直接上線，最可能怎麼壞

1. **招牌效果大多數局沒出現**：玩家背熟六條文字，整局卻只見普通連鎖。觀察開局到覺醒的機率與夜數；若產品想要高頻體驗，考慮私下抽兩封後選一封，仍允許玩家撞籤，但這是規則改動，須另量。
2. **最早覺醒的一席一路滾雪球**：神王在請神夜同時獲壽命、免債、得神、擊殺加攻；雙虎讓競爭者付稅又加落標損失。以同種子、同角色、同天命卡對照「普通／真版」，分早中晚覺醒與高低壽命看勝差，不能只報整局平均。
3. **底牌保密或成本顯示失信**：熱座交棒、袋子、競標彈窗、3D 引線、回放任一處洩漏未覺醒天命，或 UI 預算與實扣不同。對所有相位及四席逐項測，公開投影不依賴 DOM 隱藏。
4. **邊界機制互相覆寫**：落魄夜全付、雨衣免押命本金、孝女保命、押寶夜一注多押、神債回天與真版退款交錯。寫結算順序表和具體成本斷言，不能用 `assert.ok(war)` 代替。
5. **夜戰口頭生剋與程式不同**：送王船只在第 2 拍吸收；第一拍直接扣 hp 的神弓不受其保護。死去的施術隊若還能抓交替／進食，真版會把漏洞變成常見戰果。先修規則說明與來源存活判斷，再做真效果。
6. **金色公告擋住核心資訊**：真版公告如果與開標錢柱、得標卡、夜戰傷害同時佔桌心，玩家只會看見金光而不懂事件。用現有 844×390 與 1280×720 截圖治具，實際看覺醒那一格的字、音、鏡頭和操作遮擋。

## 5. 可放行條件

1. 修復現行版本字串錯版與 8 個測試失敗，分類保留根因；`sfx-wiring` 另跑長時測試，不能以略過稱全綠。修押寶夜預算與實際費用不一致。
2. 專屬測試覆蓋抽籤可重現且允撞籤、四席私密／公開投影、拍賣得標覺醒一次、普通與真版效果隔離、六組實付／夜戰／重複來源／死亡／夜規邊界；至少加入能抓住計算方向錯誤的突變測試。
3. 事前凍結對照：相同種子／角色／抽籤，普通效果對真效果；六組逐一報覺醒率、覺醒夜、全局勝率、早覺醒條件戰果、壽命支出與回補、夜戰三拍長度與護盾／回血活性。高風險組（神王、雙虎、長明）另做交叉對戰與最差情境；條件樣本不可冒充因果。舊 v0.57.37 的 8 萬局只覆蓋前三組普通版，不能替新規則簽字。
4. 真機及瀏覽器截圖確認私有資料、橫式窄螢幕與覺醒可讀性；恢復舊 A2 盲讀與 A3 真人研究屬獨立議題，本功能仍須自己的玩家理解驗收。
5. 在上述結果可審閱之前，**不宣稱 Premortem 已證明最佳平衡，不部署 v0.57.41**。P0/P1 多人仍是研究／延後項；單機 UI 的保密不能宣稱伺服器防作弊已完成。

## 6. 整體遊戲仍存在的已知缺口

本次現況截圖沒有 JS 錯誤，3D 桌與市集可進入，但橫式桌面中場的規則條、左右拍品卡字級密集，真天命 UI 需要資訊層級重排。既有 A2 的拼板舟、福壽綿長、大士爺盲讀未過；A3 滿編指認 S6 未過、再玩研究六局經使用者允許暫緩；L1e 原 H9 有水陸與雙虎未達門檻、千眼無法判讀，完整跨夜六之四模型未閉合。這些有歷史裁定，可繼續開發，但不得在新版本報告中改寫成已驗證通過。
