### 鑑別力（先證紅）

- #1：基準 V1 判紅，含 `#south > button.side「袋子」`（「袋／子」）與底列座位名 `#myDir`（「南・紅衣婆／婆」「南・青面攤／主」…）✅
- #2：**凍結字面（字的 em 框對容器外框 >1px）在基準上抓不到 `#northPrev`**——預告框高度由內容撐開，字永遠在自己的框內；實際瑕疵是框沒有上下內距（`padding:0 4px`），字壓在虛線上（`contact-before-V1.png` 夜行錄第 7 夜那格看得到上下兩行壓線）。量到的「2px」就是字的 content area 超過虛線內緣。
  依 `02 §2.1`「加嚴自行記錄」改用**加嚴版**：字的 content area（Range.getClientRects 原始框）對容器**框線內緣**（padding box）>1px。兩者單調：content area ⊇ em 框、框線內緣 ⊆ 外框，所以字面版紅的一定是加嚴版紅。改前／改後實測（同一次跑，兩欄都記）：基準字面版 V1 8／V2 1／V3 7／V4 14／V5 0 格、加嚴版 114–115 格／視口（含 `#northPrev` 8 項、最大 2px）；修後字面版 0、加嚴版 114 格／視口（全是 `#northPrev`，未修）。
- 量測中途發現並修掉的治具問題（全部在跑最終基準之前）：置中對齊時下一行不一定較靠左（原判斷漏掉「袋／子」）；段與段之間的純空白節點沒算斷點；`#northSeat` 是 `display:contents` 被當成不可見；`offsetWidth` 取整造成 9.94px 假警報；可捲容器捲出一半的鈕與行不算尺寸／不取樣；夜戰與揭盅畫面兩張截圖之間仍在演（`animations:'disabled'` 會把進場動畫快轉掉，整顆系字徽不見）⇒ 改成量測前後兩次取正在跑的動畫、比對 opacity、元素是否在量測中被重畫，任一成立標「演出暫態」。基準與修後都用最終版治具重跑。

## 各類修法（每類一個源頭）

改動集中在 `assets/safe-area.css` 末段「v0.58.3 畫面細修」＋ `index.html` 八處 markup（只加 `<span class="nob">` 分段、`textContent` 逐字不變）。

- **#1 斷行**：新 `.nob{white-space:nowrap}`＝「這一段不准拆」，只准在段與段之間（「・」後、「（」「／」前）換行：底列名字 `#myDir`、數值列 `#myPow`、底列總計 `.bsum`、押寶條標題、拍品卡部隊列 `.uline.stat`、局末排名數值、回顧格「N 次／第 N 夜」、揭盅「實付 N」。主鈕、揭盅拍品名、熱座氣色字用 `word-break:keep-all`（中文詞不拆）。底列 side 鈕 `nowrap`＋`flex-shrink:0`（「袋子」不再被擠成兩行）。
  比較過：①全部 `nowrap`：SE 667 底列放不下，`#budget` 會從左邊蓋到 🔊（實測差 3–10px）；②主鈕用 `<wbr>`：斷點仍在同一個文字節點裡，要改 11 個 textContent 寫入點；③採用：keep-all＋分段，底列讓出寬度（間距 10→6、side 鈕內距 12→8、主鈕 22→10、燒香列右外距 8→0、底列總計可在「／」前換行）。凍結點名的「蓋牌／開標」例外因此用不到（主鈕一行放得下，修後全跑沒有任何主鈕換行）。
- **#2 越框**：底列三項（熱座長名字、氣色字、「蓋牌，交給下一位」衝出底列）隨 #1 的底列寬度重分配歸零。北列預告框未修（見北列）。
- **#3 字級**：側座位卡狀態列 9→10、拍品卡說明／部隊列 9→10、系別 chip 8.5／9→10、盯上徽章 9.5→10、今夜受惠 8.5→10、選角卡壽命 9→10、夜戰系字徽維持 9px（列為裝飾例外，見例外清單）。拍品卡部隊列放大後 SE 寬放不下一行（原本 nowrap＋省略號，會吃掉「共鳴N拍」），側欄改成可在「・」後換行。

## 已知限制

- 北列（見上）未修：#2／#3／#6 各 114 格／視口。
- 拍品卡字放大後卡片變高，SE／iPhone 橫向側欄更常要捲才看得到卡底（text-fit 的「可捲」格數增加，全文仍捲得到）。
- 觸控目標多數用透明 `::after` 延伸命中範圍：量的是實際命中，但視覺上鈕還是小的；延伸範圍在 Chromium 合成量測，不是真機手指。
- 一次中途跑（改動前一版）landscape 治具量到 3 個轉場紅，全是北列 `#northPrev` 長預告頂出上緣 2–3px（本卷沒動；基準同一幾何，見本卷治具 `dbgPrev` 第 3 夜 `-3.2～67.2`）；最終跑沒走到那一夜。屬北列問題。
- 安全區是覆寫 `--safe-*` 的重建模型，不是真機；`assets/safe-area.css` 沒有版本查詢字串，瀏覽器可能拿舊 CSS（index 已 bump 0.58.3）。
- 治具 `#1` 的「句子」判準只認「，。；！？」與 `.ab`；其他說明文（例如 AI 提示句）照紅列出，由人判例外。
