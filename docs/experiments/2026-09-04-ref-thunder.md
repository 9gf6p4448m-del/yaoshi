### 誠實標註：雷女神話的圖像參照沒找到，改用文獻

## 二、每張一句

- **`eagle1.jpg`**：大冠鷲的頭是**猛禽的頭**——喙短、粗、基部黃、**上喙前端向下折成一個銳利的鉤**（不是尖錐，是折下來的鉤）；一對**大而圓的金黃色眼睛**、瞳孔深黑，眉脊壓低使眼神成為「瞪視」；頭頂與後頸有一叢深色冠羽。棲枝時整隻是**一根垂直的紡錘**：肩最寬、往下收窄、尾羽直直垂到底，翼收在體側不外張。腳短、黃、有粗大黑爪。
- **`bird1.jpg`**：台灣藍鵲的辨識全在**比例**——**尾羽長度超過頭＋軀幹的總和**，中央兩根最長、末端白；頭與胸是黑的，體羽是飽和的鈷藍，喙與腳是**強烈的朱紅**，眼是黃白色小圓點。頭小、身短、尾極長＝一個「小塊＋一條長線」的剪影。
- **`wing1.jpg`**：黑鳶展翼仰視——雙翼從身體兩側幾乎**水平**伸出、前緣是一條近乎筆直的斜線，**翼端不是圓弧，而是散開成 5–6 根彼此分離的長條指狀羽**（初級飛羽分岔），每一根都往外上翹、末端收尖。身體只是兩翼之間一根細紡錘，頭小而前伸，尾末端凹成叉形。
- **`bolt1.jpg`**：閃電的形態學——**沒有一段是平滑弧線**。它是一串**短直段**，段與段之間以**銳角**相接、方向突然改變（折線，不是曲線）；主幹最粗最亮，每分一次叉就細一階、暗一階，末梢散成一把毛。整體是「**粗主幹 → 銳角折 → 分叉 → 更細**」的樹狀。亮度是白熾的核心壓在近黑的底上。
- **`carve1.jpg`**：排灣祖靈柱——頭部佔了整塊板的**三分之一以上**；沿著頭的輪廓外圍是**一列規律排列、大小遞變的菱形**（百步蛇紋的圖騰化）；面部是**塊面鑿出來的**：眼是帶凸緣的橫長杏形、鼻是一條直脊、嘴是一個**菱形**；四肢貼身不做動勢、正面僵直對稱；手指與腳趾做成**一組平行的細凹槽**；柱下緣一整條**規律的幾何紋帶**（三角、折線、弧列交替）。通體風化成灰褐，無彩、無圓滑過渡。
- **`ember1.jpg`**：燒紅的炭——**發光的不是一顆光滑亮球**。表面是一層**灰白色的粗糙炭殼**，橘紅的光**從殼與殼之間的裂縫、坑洞裡透出來**，形狀不規則、斷斷續續。這一條直接反制 `bow` 的教訓（六位讀者把「一個亮盤＋一根桿」全讀成寶石／齒輪／輪軸）：**火種要做成「灰殼包著、從縫隙透光的一叢不規則塊」，不能做成一枚光滑的發光圓盤**。

### 雷女與火種（文獻摘要，取代找不到的圖像）

布農族〈雷女〉（中文維基百科「布農族」神話段、及原住民族委員會原住民族文獻／族語教材所錄之布農〈雷女下凡〉）：天上的**雷女**下凡與人同住，教族人種**小米**與農耕祭儀，並帶來**火**；族人違反她立下的禁忌（不得以髒手／不得偷看／不得直呼其名，各版本略異）後，雷女**乘雷電返回天上**，臨去前留下火種與小米。另阿美族與排灣族亦有「雷擊木起火，族人由此得火」的取火傳說。

這三件事直接決定本隻的造型：
1. **「火種」是被帶著走的、還沒燒起來的火**——所以是**餘燼（灰殼＋縫隙透紅）**，不是一團火焰、更不是一顆寶石。
2. **雷女是「乘雷電往返」的**——雷不是她的武器附掛，是她的**身體與翅膀本身**；所以雷紋要長在翼上（`劈裂的雷紋`），不是手上拿一根閃電。
3. **她是給予者不是毀滅者**——祖靈的「古老、莊嚴、山林的威嚴」在此，不是陰氣的凶戾；配色走風化木／骨／祖靈金，不走血紅。

## 三、一眼特徵清單（造型必做項；★＝側視也看得見）

> **本節寫下即凍結，動手後不得改**（凍結檔 `2026-09-04-acceptance-creature-batch.md`、`02 §2.1`）。M-A1 盲讀時 context-free 讀者**主動列出**的特徵須命中 **≥3 條**（出貨下限），**目標 5/5**；沒讀出的登記到 `docs/experiments/2026-09-04-creature-gaps.md`。

1. **★ 猛禽的鉤喙＋金黃瞪視眼**（`eagle1`）：喙短而粗，**上喙前端向下折成一個銳利的鉤**；一對大而圓的**金黃／琥珀色**眼睛，瞳孔深黑，眉脊壓低成瞪視。缺了鉤喙就只是一隻鳥，不是猛禽。
2. **★ 水平展開的雙翼，翼端散成數根分離的指狀長羽**（`wing1`）：雙翼從體側**幾乎水平**伸出、前緣是一條近直的斜線；**翼端不是圓弧收邊，而是 4–6 根彼此分開、末端收尖、往外上翹的長條**（初級飛羽分岔）。
3. **★ 翼緣＝銳角折線的閃電，粗主幹分叉成漸細的枝**（`bolt1`）：翼的邊緣**沒有一段是平滑弧線**——短直段以**銳角**相接、方向突變；粗的主幹分一次叉細一階，末梢最細。閃電是**折線＋分叉**，不是曲線、不是等距鋸齒。
4. **★ 喙前叼著一團「灰殼透紅」的火種**（`ember1`）：不規則的**灰白炭塊叢**，橘紅的光**從塊與塊之間的縫隙透出**；**不得做成一枚光滑的發光圓盤或球**（`bow` 的日輪被 6/6 讀成寶石／齒輪／輪軸，同型陷阱）。
5. **★ 祖靈木雕的做工＋長垂尾羽**（`carve1`＋`bird1`）：身上一列**規律排列的菱形連紋帶**（百步蛇紋圖騰化）；全身**塊面鑿刻、無圓滑過渡**的風化木／骨質感、正面僵直對稱；一條**長到過膝、超過軀幹長度**的垂尾羽把剪影往下拉成垂直物（祖靈側視 W/H ≤0.7）。

## 四、參照 → 造型的翻譯（anyCreature 沒有貼圖，全部翻成幾何）

| 特徵 | 幾何做法 |
|---|---|
| 鉤喙 | 兩段：上喙一條短 `curve` 先前伸再 `fall` 急下折（末段 taper 收尖，材質 `beak_horn`）；下喙一條更短的 `curve`，兩者之間留出口縫夾住火種 |
| 金黃瞪視眼 | `type:"eye"`，材質名 `eye`，色琥珀金 `#e0a83c`；`spread` 必須 > 顱骨該處 half-width（`bow` ⑧-4 陷阱）；上方一片薄 `fin` 當壓低的眉脊，但不得蓋住眼（`bow` judge 踩過） |
| 水平展開的雙翼 | 每側一條主 `curve`（翼骨，`mirrored:true`，宿主用 `L*` 鬆散關節以跳過 `part_attachment` — `bow` ⑧-2），近水平伸出 |
| 翼端 4–6 根分離指羽 | 每側 5 根獨立短 `curve`／`spike` 從翼骨末端呈扇形散開，長短不一、末端 taper 收尖（**不是**一片完整的翼板） |
| 翼緣的銳角折線閃電 | 翼膜用**多片小三角／梯形 `fin` 拼接**（`fin` 只吃凸多邊形，鋸齒外緣要靠多片拼），每片頂點交錯錯開＝折線；主幹一條粗 `curve` 沿翼骨、分叉兩條細 `curve` 往翼緣（材質 `glow_bolt`），逐級縮 `r` |
| 火種（灰殼透紅） | 3–4 顆不規則小 `curve`／低 `sides` 塊當灰白炭殼（材質 `ember_ash` 近白灰），塊與塊的縫隙裡塞 2–3 顆更小的 `glow_bolt`／`glow_ember` 亮塊——**光從縫裡漏出來，不是一個亮盤** |
| 菱形連紋帶 | 一列小 `fin` 菱形（4 邊凸多邊形 ✓）沿胸／頸排一圈，交錯兩色（祖靈金＋靛藍），**不用 `colors.arcs`**（低 `sides` 會被角度格吸附，`nail` ⑥-2） |
| 塊面鑿刻感 | `build:"rigid"` ＋**所有主要 volume `faceted:true`** ＋斷面 `exp ≥4.5` ＋ `smooth_angle` 24–30（19:10 模板規則） |
| 長垂尾羽 | 一條長 `curve` 從尾根近乎垂直往下垂（不是往後平伸），長度 > 軀幹長；末端 2–3 根分岔羽尖 |
| 祖靈金落在翼紋 | 簡報指定「祖靈金:翼紋」——金色只給翼上的雷紋 `fin`／`curve`，其餘部位走炭黑＋風化木褐 |
