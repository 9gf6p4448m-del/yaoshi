- **短版通過 2/27**（虎姑婆指甲、射日神弓）；及格線 ≥24 未達。
- **完整版本來就不可辨 14/27**（依量表對照組規則不算短版的錯）：媽祖令旗、山豬牙飾、破軍旗、林投姐髮簪、虎爺印、五營旗、香灰符、魔神仔紅帽、獻祭刀、千里眼銅鈴、福壽綿長、山神庇佑、陰陽眼銅錢、拼板舟。
- **短版未過但完整版可辨 11**：多數是完整版也只到 3–4 分邊緣，短版差 0–1 分；只有王爺劍（full 4/3 → short 2/2）、祖靈之眼、雷女之火、巴冷公主珠鍊短版明顯掉分。
- **判讀**：短版對完整版的落差小（Q1 −1～−2 支、Q2≥4 −3～−4 支），**主因是招式演出本身可辨性低**，兩位讀者獨立指出同三件事：①特效是常駐造型（旗、火把、蠟燭）第一格就在，讀不出「出招」②只用腳下光環／細白虛線的招太多互相分不出 ③特效顏色（橘、白、淡粉）與暗紅地面、紫夜空對比不足。好認的招都是「法寶本體直接畫出來」（指甲、弓＋太陽、鋸齒閃電、珠鍊、雨衣）。
- 限制：三張靜態格、每格 370px，動態與時序丟失，分數偏低；下一輪材料應改成更多幀、更大尺寸，基準同法重量。
- 迴圈第 1 輪即停（未交修者）：依量表對照組規則，這不是短版時間軸能修的問題，交使用者裁「招式可辨性卷」。
