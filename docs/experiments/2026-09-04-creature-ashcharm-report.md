## ⑤ 本卷實測到的新引擎陷阱（已同步寫進 `ashcharm.json` 的 `_traps` ⑧–⑮）

**⑧ `profile` 每列的兩個半徑是 `(Z, X)` 不是 `(X, Z)`** ← 最貴的一條，建議加進派工必附清單
直立主鏈下，`[t, a, b, opts]` 的 **a 是前後深（Z）、b 才是左右寬（X）**。本卷 r3 照 `(ru=X, rv=Z)` 寫，chest 那列 `[0.60, 0.258, 0.156]` 實測把 +Z 表面推到 **0.247**（＝第一個數字），整隻變成「側面比正面寬」，ward 硬條件直接反過來；把兩個數字對調後 chest 表面回到 0.151。
量法：跑 `engine/core/compile.js` 的 `compile()` 掃 volume 頂點的 `zmax`，**不要靠 profile 心算**。

**⑨ 起始端 `caps:"ngon"` 在大斷面上會產生反向三角**
spine 底環（0.306×0.402、`exp` 4.4–4.6、`sides` 20）配 `caps:["ngon","ngon"]` 固定 **8 片 flipped tris**（`sides:12` 時 6 片、`sides:20` 時 8 片），bind pose 就紅、三支動畫跟著全紅（37 條 BLOCK 裡有 16 條源自這一個）。逐項實測：

| caps | 結果 |
|---|---|
| `["ngon","ngon"]` | ✗ 8 flipped |
| `["ngon","flat"]` | ✗ 8 flipped |
| `["ngon","none"]` | ✗ 8 flipped |
| `["flat","ngon"]` | ✓ clean |
| `["flat","flat"]` | ✓ clean |
| `["none","none"]` | ✓ clean |
| `["none","ngon"]` | ✓ clean |

＝**只跟起始端那個 ngon 有關，與收尾端無關**。本檔用 `["flat","ngon"]`。（`ring_step` 拉大只會把 flipped 數從 8 降到 1，是掩蓋不是修好。）

**⑩ 臉上的小片要放在「量出來」的表面外**
r3 照 profile 心算把眼縫／火口／胸牌放在 z=0.148–0.182，judge 量到 `mouth_glow` 與 `gold_trim` 的 share 在 **front/side/tq/reartq/top 五個視角全部是 0**（整片埋在體內，`cli.js` 全綠、肉眼在 512px 也看不出來）。先用⑧的探針量出該高度的表面 z，再往外放 0.01–0.02。

**⑪ 裝飾層掛鬆散關節＝ `part_attachment` 整條被跳過**
`compile.js:569` 算不出 `hostChain`（鬆散關節不屬於任何 chain）→ `checks.js:306` 直接 `continue`。本檔的**朱砂紅印、墨字、香腳火點**掛在鬆散關節（`FuD*`／`JossT*`／`BrowFu`／`HandFu`）上——它們本來就長在符紙與香腳上、不長在竹骨或身體上，這是正確的宿主關係，但代價是**這三類部位的貼合沒有機器在守**，只有肉眼看 hero／stage-lit／front 三張渲染圖核對過。符紙本體（`charm_paper`）與符邊（`charm_edge`）host 在 `wala`／`walb` 的鏈關節上，`part_attachment` 全程有在守。同 wangchuan 報告 §2 的盲區。

**⑫ 一片一片吊在弧形橫桿上的黃色長方板＝母衣／背旗／屏風**（六位讀者一致）
四個修正要同時做才第一次有讀者在主印象說出「紙紮／符咒」：(a) 橫桿攤平（弧形放射＝翅膀的文法）(b) 紙色 `#c9a92e`→`#e8c93a`（芥末橄欖黃一律讀成竹／木）(c) 墨字由一條通貫改成「細直軸＋五道長短不一的短橫筆」（長條＝板縫）(d) **把符也貼到身上正對鏡頭**——3/4 機位下背後的符牆永遠是斜的。

**⑬ 低多邊形做不出「香灰」**（六位 0/6，一律讀成石／金屬／混凝土／石礫／骨片／鉚釘）
已否證：灰調 `#5b5852`→`#918a7c`（front median lum 56→84，上限 90）、階梯層理、底圈圓瘤、底圈扁碎片、外露斷段 `curve`。同 tiger_c 白毛邊／boat 木紋／wuying 紙紮感／wangchuan 焦黑的「表面質感族」。

**⑭ 等距階梯狀 profile ＝ 石燈籠／地藏像的橫向刻痕**（r6 兩位逐字）。要做「堆積」不能用等距階梯。

**⑮ 底圈零件的下緣穿到 y<0 會把全高撐出 band**：碎灰片 fin 的 v 半高 0.035 讓全高由 1.235 變 **1.269**（band 是 1.2–1.25），而 `cli.js` 與 `judge` 都不會警告。底圈零件的中心 y 要 ≥ 半高。
