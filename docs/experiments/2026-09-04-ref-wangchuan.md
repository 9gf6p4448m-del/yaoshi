## 二、看到什麼（逐張，親眼所見）

**`side.jpg`（全船側面）**
金黃底的木船，**船首與船尾都往上高高翹起**，中段最低——舷線是一道很深的新月形弧。舷側上緣是一整排**紅框方形彩繪板**，每格畫一位神將人物，橫向連成一條帶；帶的下方是**數條平行的彩色橫紋**（由上而下大致為米白、桃紅、青綠、米黃），再往下是金底上的**綠身龍紋**與雲紋浮雕。船首（右）近上緣處有一顆深色的**圓眼**。甲板舷緣上**站著一整排小人偶**（彩繪神將偶），一個接一個排成直線；船尾（左）有一座紅黃彩繪的**艙房**。船中偏尾處立著一根細桿，掛白色小旗。

**`build.jpg`（船首特寫）**
仰角看船首：船首向上翹起後收成一個外撇的方形船首板，上面鑲一大幅紅框彩繪。船舷上清楚可見一顆**大船眼**——淺色（白）眼眶包著一顆深色圓瞳，畫在金黃船舷上，比周圍任何裝飾都醒目。眼下方就是那組**平行彩色橫紋帶**（粉紅／綠／米白），紋帶下方是金底綠龍。左側甲板上**一列小人偶並肩站著**，看得出頭與身體兩截。

**`burning.jpg`（燒王船）**
夜裡整艘船在燒。上半仍認得出**一片豎立的方帆**——深色的矩形帆面，上面橫著一道道**桁條**（水平的橫線）；帆的旁邊是**豎直的桅杆**，桅頂垂著紅色長條旗。船體下半整個沒入火裡：木頭是**焦黑的剪影**，橘紅色火焰從船腹一路往上舔，船底下是一大片燒紅的金紙餘燼。舷邊還看得到一排直立的短柱（欄杆殘骸）與一面紅色令旗。

## 三、一眼特徵清單（**凍結**，寫 JSON 之前訂下，此後不得再改）

> 這五條就是造型的必做清單，也是盲讀 Q2「逐條列出看到的特徵」要命中的清單。
> 出貨下限 ≥3/5；本卷目標 **5/5**（凍結檔 2026-09-04 18:40 使用者裁定）。

1. **首尾同時高高翹起的木船身**——舷線是一道深弧（新月形），船首與船尾都往上翹成尖端，中段最低。（`side.jpg` 全景、`build.jpg` 船首）
2. **船舷上的大船眼**——畫在船首側舷上的一顆圓眼，淺色眼眶包著一顆深色圓瞳。（`build.jpg` 正中最清楚、`side.jpg` 右側）
3. **舷側一整排紅框方形彩繪板，其下並排數條平行的彩色橫紋帶**（米白／桃紅／青綠）。（`side.jpg`、`build.jpg`）
4. **甲板上並排站著一列小人偶**（紙紮／彩繪神將偶，一個接一個排成一直線，看得出頭與身兩截）。（`side.jpg` 中段、`build.jpg` 左側）
5. **豎立的桅杆＋帶橫桁條的方帆，船身下半正在燒**——木頭焦黑、橘紅火焰從船腹往上竄。（`burning.jpg`）

## 四、翻成 anyCreature 幾何的對照表（`ART_BIBLE` §5 材質語言 → 幾何／頂點色）

| 特徵 | 幾何做法 |
|---|---|
| ① 首尾高翹 | `hull` 主鏈**水平臥在 X 軸上**、7 個關節排成新月形；兩端 profile 收成 0.02 的針尖，中段 rh 0.205 → 舷線自然成深弧。兩端各加一片外撇的**船首／船尾板** `fin`（紅框＋米白畫心兩層） |
| ② 船眼 | 三層疊板（`boat` 報告 ③ 的船眼寫法）：淺色八角 `oculus_ring` → 深色小八角 `oculus_pupil`，貼在船舷 ±Z 兩側 |
| ③ 彩繪板排＋橫紋帶 | 板排＝沿舷線分四段、每段一片 `panel_frame` 紅底板＋一片內縮的 `panel_face` 米白畫心＋豎向分隔肋；橫紋帶＝`stripe_cream`／`stripe_rose`／`stripe_jade` 三條薄 `fin` 沿舷線分段舖（**不用 `colors.arcs`**，理由見 §五） |
| ④ 一列小人偶 | 7 具 `curve` 組：`paper_robe` 錐柱（袍）＋`paper_head` 短柱（頭）＋`paper_hat` 尖冠，等距站在甲板上，其中 3 具站在艙口的火光裡 |
| ⑤ 桅杆方帆＋燒 | `mast` 垂直鏈（volume）＋四片橫向 `sail_cloth` 帆板（分別 host 在四個桅關節上，接縫即桁條）＋`batten_wood` 橫桁；燒＝`char_plank` 焦黑破板 ＋ `glow_hull` 火舌（貼舷往上捲）＋ 艙口 `mouth_glow` 火光 |

**系別色帶（簡報指定「香火橘:船腹」）**：`colors.arcs` 在 `hull` 的下半（sym 26–56）舖一條高飽和陰火橘 `#d4530c`，就是燒到一半的火線；其餘全是中性暗色。
**發光材質（簡報指定）**：`mouth_glow`、`glow_hull` 兩個，原樣出現在 GLB materials。船眼**不做成發光眼**——參照上的船眼是畫的不是亮的，且材質名要避開 `js/creature-figures.js:51` 的 `/^eye(_|$)/`（所以叫 `oculus_ring`／`oculus_pupil`，不叫 `eye_ring`）。

## 五、為什麼橫紋帶不用 `colors.arcs`（動手前算出來的）

`colors.arcs` 的 `sym` 是**斷面角度**不是世界高度。斷面用 `exp ≥4.5`（模板規則）時是方塊形，同一段角度在船側那一片平面上會**極不均勻**地展開：實算 `sides:48`、`exp 5.2` 時，sym 82.5 落在船側高度 −0.457·rh、sym 90 落在 0、sym 97.5 落在 +0.457·rh——**中間 46% 的船側高度上一個頂點列都沒有**，畫不出等距的細橫紋（只會得到一道大漸層）。所以橫紋帶改用實體薄 `fin`；`arcs` 只負責大面積的分區（焦黑龍骨／香火橘船腹／暗色甲板）。
