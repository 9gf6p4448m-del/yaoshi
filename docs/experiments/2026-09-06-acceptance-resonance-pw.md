## 候選（三個，全部寫進引擎、由 PW_RES_MODE 選）
- lv＝min(PW_RES_CAP=3, 同系件數 c − SET_MIN + 1)，c 走既有 `facCount()`（雷女／五營旗／浮標的 onFacCount +1 仍生效），

- M1 同系列陣（hp）：該系的拍，該系每隊每隻 hp/max +lv（同月相的寫法）。
- M2 共鳴拍（atk）：該系的拍，該系每隊 atk +min(2,lv)（走既有 t.bonus）。
- M3 共鳴增員（隻數）：召軍時該系隻數最多的那隊多 lv 隻（複製該隊單位規格）。

## 驗收條件（動手前訂，凍結；n＝10000、seeds 1..n）
- **R0 kill switch**：PW_RES_MODE=0 時 `trace(1..20)` 與 31504b0 逐位元組相等；M1／M2／M3 各自必不相等。
- **R1 活性**：預設 AI 桌 runMany n=10000，共鳴至少一側生效（lv>0）的正式對決比例 **≥20%**（用 `PW_RES_STAT` 純計數，只計 resolveBattles 呼叫的場次，不計 AI 估價試打）。<20% ＝仍是裝飾，該候選不過。
- **R2 有感但不支配**（袋對袋 duelBags）：程式枚舉「同系 3 件 vs 三系各 1 件、總 p 相等」的配對，先在 MODE 0 量基準，只留基準勝率（不計平手）落在 **40–60%** 的配對當有效對照，有效配對 **≥3 組**；各候選下成套袋勝率須落在 **55–75%**。基準不足 3 組有效對照＝該條「無法判定」，明寫。
- **R3 無支配策略**：splitter／greedy／hoarder／specialist 座位 0 勝率各 **≤40%**（同卷 D D-A3 門檻），並報與 MODE 0 的位移（位移只報不判）。
- **R4 命格活性**（單元斷言）：袋含過陰咒、life<15 的一側 lv 比同袋 life≥15 大 ≥1；山神庇佑 life≥30 同理。
- **R5**：既有 5 套 `tests/*.test.mjs` 綠；Playwright 對決一局（候選之一開啟）0 console error。
- **R6**：`docs/proposals/2026-09-06-resonance-paperwar.md` 存在，含三候選閘門結果表＋建議，**結尾是給使用者的裁定題，不是已改的預設**。
