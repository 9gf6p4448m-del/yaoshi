# 六組真天命：覺醒當下焦點席因果比較

日期：2026-09-23。對照為普通效果、真效果關閉的 ordinary-ai-off。固定種子 10001..20000 共 10,000 局、4,886 個覺醒點。依[事前契約](acceptance.md)及[設定](arms.json)，每鏈分母為焦點席實際拍賣入袋完成自己指定配方的第一次覺醒。**原案與削峰候選均未通過六鏈門檻；不具發布資格。**

## 方法與可驗證範圍

每一處理局都從真效果關閉起跑，固定同種子、四封私函、座位零追件策略、其他 AI 規則與公開市場。覺醒 callback 在任何真效果啟用前，比對普通對照與處理分支的完整遊戲狀態、拍賣區域狀態、整局 runner 區域狀態、局外連鎖持有追蹤器、物件參照關係與遊戲／UI 兩支 RNG。完全一致才切換焦點席的原案或候選真效果；其他三席的真效果持續關閉。由此是**固定種子的確定性重建、同檢查點分流**，不是從封存檔反序列化 JavaScript 呼叫堆疊。對照回放另須與原普通 raw 的覺醒、得主、終局壽命、局長逐值相同。

配對勝率差以焦點席是否贏得整局計；95% 區間按 game seed 群集重抽樣 10,000 次，固定重抽樣種子 20260923。每鏈至少 300 個檢查點；事前通過線是區間**全落於 +3..+10 百分點**且有不同於普通版的真事件。區間全落在界外是 fail，跨線是 incomplete。早／中／晚夜分層只作描述，不當成全鏈通過替身。

## 審視與下一個優化版本

- **不採削峰案為預設。** 它沒有讓任何一條從 fail/incomplete 轉 pass，且神王和長明的焦點增益較原案低；目前沒有削峰可改善玩家體驗的獨立證據。
- **也不宣稱原案已平衡。** 水陸、千眼、雙虎、血祭四條未達事前 +3pp 最低有益線。優先量玩家可感知收益和完整收支：千眼能否在下注時實際運用情報，雙虎與血祭的威嚇是否造成避標，水陸的補貼是否只改壽命不改關鍵決策。普通版雙虎／血祭 H9 也已 fail，應先處理普通回報，避免單純加碼真版掩蓋根因。
- 神王原案和長明原案接近最低線，保留為下一輪候選基礎；先做早醒神王滾雪球、長明實際吸傷與拖局壓力試驗，再設新候選 ID 和預註冊門檻。不要依這批結果回改本批臂。
- 需要玩家盲讀「誰、兩件材料、真版多什麼」、完整六之四跨夜模型、歷史 H9 修正或明確新裁定。現行 releaseEligible=false，版本仍是 0.57.40。
