## 2. N7 撤案：它確實是死碼

```
git show 401f923:index.html > old-401f923.html
node -e "...loadGame('old-401f923.html'/'index.html') 各跑 trace(1..20)，顯式 LEGEND_ON=true/false..."
```
```
顯式 ON：401f923 vs 二版（N7 拔除）逐位元組相等： true  長度 386483 386483
顯式 OFF： true
```
**解釋**：`rollers` 的聯集條件「`h≥INC_PITY` 的活人」與 `aiIncense` 的天井跳過，在任何合法局面都取不到——
`h` 只能靠燒香增加，而 `h` 一到天井那一夜就必請並當夜關龕，所以「還開著的龕上有人 `h≥P`」不可達。
拔掉它之後 trace 逐位元組不變，**正是它從來沒有生效過的直接證據**（也回答了派工「若不同要解釋」：沒有不同）。
