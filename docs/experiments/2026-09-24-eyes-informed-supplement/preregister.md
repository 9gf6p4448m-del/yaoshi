# 千眼知情策略與玩家理解補充驗收（事前登記）

日期：2026-09-24（Asia/Taipei）。狀態：**策略診斷已登記；量測未執行；真人盲讀未執行**。工作基準 `feat/l1-water-chain`／`344083ab856e57a873ba5a105519e5db41298693`，產品仍為 `v0.57.40`。本卷補充既有 20 局探索樣本，不覆寫它，也不改產品碼、遊戲數值或正式 H1/H9 門檻。

## 問題與固定策略

既有 `eyes-informed-v1` 在 20 局中有 10 次出價決策與同局面的盲策略不同，但勝局數相同。這只證明情報會改變決策，不能證明決策變好、千眼帶來勝率優勢，或玩家看得懂畫面。

沿用 `tests/tools/l1-information.mjs` 已存在且固定的三臂，不按本次數據調策略：

- `informed-normal`：座位 0 使用 `eyes-informed-v1`，有千眼合法額外預告與前夜第二高標資訊。
- `increment-blind-normal`：同一決策函式移除千眼新增的預告與第二高標記憶，保留既有資訊能力。
- `informed-zero`：所有席位停用普通千眼效果；座位 0 仍執行知情策略。此臂只作機制診斷，不是乾淨的策略單因子對照。

固定原 CFG、座位 0 青面、其餘三席引擎 AI、同種子配對。種子 `20001..30000`，每臂 10,000 局，共 30,000 局；使用既有 runner 的明確 seed API，不呼叫其從 1 起算的 CLI。此範圍先於本次結果固定，且不與 2026-09-23 普通版正式 `10001..20000` 種子重疊。不得因結果挑掉種子或更改策略後把本樣本當新版本證據。

## 事前指標與解讀規則

1. **主要策略結果**：`informed-normal − increment-blind-normal` 的座位 0 配對勝率差（百分點），列出兩臂勝／負不一致的配對數及以 seed 配對重抽樣的 95% 區間；同時列出配對局長差。這是凍結 AI 桌上的估計，不是真人優勢或平衡通過門檻。
2. **情報被消費**：策略呼叫數、額外預告可見次數、合法第二高標可見次數，以及知情與盲策略在相同呼叫快照下實際出價不同次數。後兩項可重疊，不能相加成「獨立可用情報數」；出價不同不表示更正確。
3. **持有者結果**：持有過千眼者及持有者贏局只作分臂描述。持有是策略與玩法之後的狀態，各臂分母不同，不能把持有者勝率差解讀成因果效果。
4. **有效性與限制**：所有 seed 均須在三臂各出現一次，角色／CFG 一致，且原始逐局列與 source/tool hash 留檔。`playPolicyGame` 會在座位 0 死亡後停止，不是完整 AI-only 對局；種子配對亦不能凍結資訊改變後的所有後續局面。
5. **不設勝率 pass/fail**：此補充樣本不能改變舊千眼 H9 的 `incomplete`，也不構成正式 H1、H9、六之四、天命或發布驗收。只有另立版本、先凍結目標與門檻，再以新樣本測新策略，才可判候選。

## 真人冷讀／盲讀方案

**目前沒有真人參與者或盲讀結果**。此方案是待執行驗收，不可寫成已通過。招募至少 5 位未讀本卷、未玩過天命版的玩家，使用實際互動版而非只看文件；在 844×390 與 1280×720 各至少觀察一輪。主持人不先說明千眼規則，不提供答案，分別記錄開標覺醒公告與玩家主動打開私函後的回答及操作。

固定任務：

1. 只展示覺醒公告約 5 秒，遮住後詢問：「剛才發生什麼事？你會去哪裡看原因或效果？」不要預設玩家此刻應已背出未顯示的規則。
2. 讓玩家自行找到並查看袋中天命，再詢問：「誰覺醒了、靠哪些材料、效果何時生效、作用在誰身上？」記錄是否需要主持人提示、是否能找到關閉或返回操作。
3. 詢問：「覺醒之前，其他席能知道哪些資訊？覺醒之後哪些資訊公開？」記錄把密函誤認成全桌可見、把效果誤認為全桌生效的回答。
4. 回到可操作桌面，請玩家指出下一夜可用的預告與上一夜第二高標資訊；記錄是否把不能看的第四件、別席的私有資訊或預估價誤當成已揭露事實。

暫定可讀性目標（是本方案提出的驗收值，尚未批准為正式產品門檻）：5 人中至少 4 人能在不提示下找出自己的效果並正確說出觸發時點／受益席；至少 4 人能分清覺醒前私有與覺醒後公開；至多 1 人誤判效果施予全桌或資訊已公開。任何人若無法找到關閉／返回操作，或把未揭情報說成事實，均記為具體失敗例，先修資訊呈現再重測，不藉改數值處理理解問題。

## 審讀時已見的畫面風險（非真人結果）

檢查既有 844×390 覺醒截圖時，公告有玩家席位與真鏈名稱，但同一畫面沒有兩件成型材料與效果摘要；揭示後的私函包含效果文字，但截圖底部內容延伸出可視範圍，畫面也未顯示明確的關閉／返回控制。這支持執行上述任務，尚不足以斷言實機無法捲動或關閉。**優先建議**是讓覺醒公告加一行短效果與「查看材料／完整規則」入口，並在長私函中提供明顯的返回控制；不改觸發、費用或效果係數，待玩家盲讀後再定案。
