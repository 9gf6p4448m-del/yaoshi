## 方法與有效性

逐局 raw 共 30,000 列。獨立重算驗證每臂 10,000 個唯一 seed、完整覆蓋預定範圍、同 seed 三臂角色相同，且座位 0 都是青面；所有檢查通過。主要區間採 10,000 次 seed 配對百分位 bootstrap、Mulberry32 固定 seed `20260924`、2.5%／97.5% 最近秩分位。這種區間是本補充分析方法，不是原 H9 驗收方法。

可見預告與可見第二高標次數可能發生在同次呼叫，不能相加成獨立機會。`informedVsBlind` 是同一局面直接比較兩份合法標單，證明額外資訊確實影響決策；不判斷改變是否正確或有利。每局持有千眼的條件分母不是隨機分派，持有者勝率僅描述，不作因果解讀。

`informed-normal − informed-zero` 的配對勝差為 +1.64 pp（95% bootstrap +1.23 至 +2.05）。但 zero 臂會對**全桌**關閉千眼效果，改變持有人能力與對局路徑；它不是只移除座位 0 資訊策略的單因子對照，不能把此差值歸因為資訊策略收益。

## 獨立畫面覆核與建議

本輪用定向狀態產生了千眼覺醒／私函／四件預告的實際畫面，非真人測試、也非自然抽籤樣本。手機與桌面 pageerror 均為 0；使用正確 SVG MIME 的截圖伺服器下，兩尺寸 broken image 數皆為 0。844×390 私函確實可捲動，但關閉鈕低於初始視窗；1280×720 內容與關閉鈕均在首屏。證據：[手機覺醒公告](evidence/eyes-awakening-844x390.png)、[手機覺醒後私函](evidence/eyes-private-letter-844x390.png)、[手機四件預告](evidence/eyes-four-item-preview-844x390.png)、[桌面覺醒公告](evidence/eyes-awakening-1280x720.png)、[桌面覺醒後私函](evidence/eyes-private-letter-1280x720.png)、[桌面四件預告](evidence/eyes-four-item-preview-1280x720.png)。

兩種尺寸的覺醒公告都有指出玩家席位與天命名稱，但沒有同時說明兩件配方材料及真效果。私函有完整規則；程式的 modal 設為 `max-height:88vh; overflow-y:auto` 並含「關閉」鈕，因此不是無法捲動或缺少關閉機制。手機長內容把關閉鈕推到視窗下方；桌面不會。四件預告在 UI 上以同一串「明夜預告」列出，沒有標出其中哪件是天命額外增加的第四件。以上是可直接檢查的呈現事實；玩家是否能理解增加的項目、發現捲動及找到返回，仍需真人冷讀確認。

**目前風險最高且不破壞平衡的優化方向**是資訊呈現，而非加強效果：

1. 覺醒公告用一行短句補「兩件材料 → 本鏈一項真效果」，並讓玩家能回袋子看全文；沿用現有 1.5 秒演出，不另疊第二張大型遮罩。
2. 私函保留細則，加入清楚的「向下還有內容」提示，並讓返回／關閉控制在手機初始視窗容易找到。不能讓文字擋住下注主鈕或 3D 開標焦點。
3. 千眼資訊標示「預告」與「上一夜實際第二高標」的時間差，並以小型「千眼多看」徽章指出額外第四件，避免玩家把新增情報和前三件混在一起，或將預估行情誤讀為必然得標／即時公開價格；不額外揭露別席密函。
4. 保持六組真效果原 R2 作候選基線，不因本次 AI 點估計或 zero 臂差值加減數值。若要改 AI 追件，需另立 `eyes-informed-v2`，事先定義為何這種情報轉成更好的購買，不用本次樣本回調策略。

## Premortem 與下一關

若把本策略或這張資訊卡直接當成「千眼已平衡」，最可能的失敗方式是：玩家確實多看見資訊、AI 約五分之一對局改過標單，卻沒有可量出的勝率改善；玩家反而把「看到第二高標」理解為可預測下一件價格，為錯誤訊號多付壽命。若公告一次塞入配方、效果和玩法術語，窄螢幕又可能遮住桌面與關閉鈕，解釋變完整、操作反而更差。故改文案要走一行摘要加主動展開，交由盲讀驗證，不把規則全塞在覺醒彈窗。

下一個必要驗收是照[事前盲讀方案](preregister.md#真人冷讀盲讀方案)與[主持記分表](blindread-scorecard.md)找至少 5 位未接觸本卷的玩家，觀察公告理解、密函探索、資訊可見範圍與返回操作；在實際執行前，本項仍 `incomplete`。此補充不關閉普通千眼 H9 `incomplete`、正式六之四缺口、其他普通鏈 fail 或發布關口。
