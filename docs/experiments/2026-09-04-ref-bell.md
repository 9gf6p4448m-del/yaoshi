- `01`：綠面千里眼，**右手抬起、前臂橫過額頭上方、掌心朝下**作遠眺手勢；左手握一根紅色長桿；頭上兩支向後彎的角、額前一條金冠帶；眼球外凸、眉心與臉上有金色圓釘；上身赤裸有胸肌，**一條青綠色披帛從兩肩往外飄開、垂到膝**；腰上金色獸面（虎頭）腰帶扣，下接一整片金色雲紋戰裙；腳踝一圈金環。
- `02`：兩尊大仙尪仔並立，**頭大得離譜**（約佔可見身高 1/3）；紅面／綠面、粗黑毛眉、獠牙外露、頭頂兩支白角＋兩顆絨球；胸前一條紅綬帶斜披、**中央一面圓形護心鏡**；下身一整片金銀獸面腰甲＋寬繡袍；臉側垂一圈稻草色鬚。

## 三、五條一眼特徵（造型的必做清單；盲讀命中目標 5/5，下限 3）

1. **★ 倒扣銅鈴頭**（側視可見）：整顆頭是一口**口朝下的鐘形銅鈴**——頂上一顆吊鈕、圓肩上一片**格狀乳釘**、鈴身兩道**橫向凸帶**、下緣**鈴口向外張成一圈厚唇**。側視剪影就是「鐘」：有裙緣、有直邊（與 `eye` 的球面、`buoy` 的圓球、`raincoat` 的鐘形帽兜靠「有脖子＋有唇緣＋有乳釘」分開）。來源：`05` 倒扣形與橫帶、`06` 肩／腰／唇三段、`07` 乳釘方陣與厚唇。
2. **★ 鈴舌就是瞳孔**：鈴身正面開一個**大塊近黑的暗窩**，窩裡懸著一根**鈴舌**，鈴舌下端的圓球**發金光**——那是這隻唯一的眼睛（千里眼＝望盡千里的那一隻眼）。暗窩＋亮瞳＋一點高光三層都要有。來源：`05` 鈴舌從鈴口探出、`04` 只露一隻大眼的獨眼特寫。
3. **★ 手遮額遠望姿**：一隻手抬起、**前臂橫過鈴口上緣、掌心朝下**作遠眺狀；另一隻手垂在身側**握一把儀仗斧**（黑刃／紅桿）。來源：`01` 遮額手勢最直接、`03` 握斧與抬手。
4. **★ 神將武甲身**：寬肩**雲肩**＋胸前**圓形護心鏡**＋**獸面腰甲**＋硬折戰裙；兩肩往外披開一大片繡袍／披帛，**正面寬得像一堵牆**（ward 的門神感）。來源：`01` 獸面腰帶＋雲紋戰裙、`02` 護心鏡＋紅綬帶、`03` 雲肩、`04` 寬過高的繡袍。
5. **★ 香火橘鈴口＋鎏金**：全隻唯一的高飽和色是**鈴口那一圈橘紅**，配**鎏金乳釘／金唇線／胸前紅綬帶金流蘇**；其餘是青銅暗色與灰甲。來源：`05`／`07` 的青銅暗底、`02`／`04` 的紅金儀仗色。

**側視可見打星**：1（銅鈴頭）、3（遮額手臂與斧）、4（雲肩／披袍的寬）三條在側視剪影上讀得到；2 主要靠 hero／stage-lit 的 3/4 視角；5 是配色，兩張圖都讀得到。

## 四、圖騰化／風格化在特徵之上（§0.5 第 4 條）

低多邊形化與神格化都做在特徵之上，不取代特徵：銅鈴仍要是銅鈴（乳釘、橫帶、厚唇缺一不可），遮額仍要是遮額（前臂必須橫過鈴口上緣、掌心朝下）。
**刻意不做的兩件**：(a) `01`／`02` 的**綠面／紅面人臉**——本隻的頭已經被銅鈴取代，臉不存在，眉眼獠牙一律不做，改由「暗窩＋鈴舌瞳」承載五官；(b) `03` 的**虎皮橘黑條紋裙**——那是 `tiger_c` 已佔的視覺語彙，且會把香火橘從鈴口搶走，改成硬折素面戰裙＋獸面腰甲。

## 五、動手前先算好的三件事（不是撞牆後才發現）

1. **側視 W/H ≥0.9 是本隻的硬條件**（凍結檔 2026-09-05 凌晨；本隻是人形 ward，不在船／牆型豁免內）。`silmetrics.mjs:53` 的 `long = s.x > s.z ? 'x' : 'z'`、`:57` 的 side 視線取**短水平軸**，所以 **side 的 W ＝ max(X, Z)**。ward 又要求 X ≥ Z，因此 side W/H ＝ **X / 全高**。全高定 1.245 → **X 必須 ≥ 1.121**。載體只能是特徵④的披袍：兩片繡袍尖端各推到 x ±0.58 → X ≈ 1.16、W/H ≈ 0.93。這條在寫 JSON 之前就決定了披袍的尺寸，不是事後補的。
2. **頭佔比**：凍結檔 18:00 守則①要求頭 ≤ 全高 1/4 或 ≥ 1/2，不落中間。鈴口 y=0.912、鈴頂含吊鈕 y=1.215 → 頭高 **0.303 / 1.245 ＝ 24.3%** ≤ 25% ✅。鈴的口徑 0.336 對高 0.303 ＝ **1.11**，與 `05` 實物（寬高約 1:1）同族。
3. **鈴口的橘要用實體幾何，不能用 `colors.arcs`**：`compile.js:219` 的 `sym` 是**斷面角度**不是世界高度，橫向的環帶用 arcs 畫不出來（`wangchuan` ⑥-6）。所以鈴口唇做成**獨立的一條 `lip` 鏈**（自己的 volume、材質 `glow_bell`），根環塞在鈴身內側（r 0.130 < 該高度鈴身 0.147）以過 `root_containment`。乳釘同理走 ㉛「繞曲面排一圈用短圓柱 `curve`、不用平板 `fin`」。
