|---|---|---|---|---|

## 答案鍵
- r1：1＝西→槽2　2＝詛咒 北塞南　3＝南→槽1　4＝東→槽1　5＝詛咒 西塞東　6＝北→槽2
- r2：1＝東→槽1　2＝南→槽1　3＝詛咒 西塞東　4＝北→槽2　5＝西→槽2　6＝詛咒 北塞南
- r3：1＝詛咒 北塞南　2＝西→槽2　3＝南→槽1　4＝詛咒 西塞東　5＝東→槽1　6＝北→槽2
（槽號 0 起算；受試者用 1 起算的「第幾號」，槽1＝2 號、槽2＝3 號。）

## 受試者原答（逐字摘要）
r1：六張全「看不出來／低信心」；只有 strip-5（詛咒西塞東）答「甲：東拿走紅色方形拍品」，strip-2（詛咒北塞南）答「乙，推的人可能是東」。
r2：clip-1 東拿走 2 號（低）✓；clip-2 南或東拿走 2 號（低）✗；clip-3 乙 西塞給東（低）✓；clip-4 北拿走 3 號（低）✓；clip-5 西拿走 3 號（中）✓；clip-6 乙 東塞給南（低）✗。
r3：seq-1 甲 南拿走紅包（低）✗；seq-2 西拿走 3 號（中）✓；seq-3 看不出來 ✗；seq-4 甲 東拿走紅包（中）✗；seq-5 北或東拿走 4 號（低）✗；seq-6 看不出來 ✗。

## 讀不出來的共同原因（受試者依據歸納，未驗證的假設）
1. 寫實手在牌桌鏡頭下很小、膚色接近紙紮人偶，手掌常被讀成人偶自己的手臂；手臂起點在取景外，判不出是哪一席。
2. 取景二選一的兩難：r1 鏡頭貼近（跟著法寶走）→ 抓起與拿走在畫面上幾乎不動；r2／r3 退到整段路徑 → 手更小。
3. 詛咒（r2 北塞南被讀成東塞南、r3 兩組都讀成「拿走」）：施放者手掌蓋在堆頂推、最後受害者把堆拖回去，連拍上像「受害者把紅包拿走」。
這幾條都碰到本卷範圍外的東西（鏡頭重設計、手的尺寸／角色手變體），留給使用者裁定。

## 最終採用
r2 版（分數最高；r3 的 straight 已撤回）。最終證據跑在 r2 版上。單一受試者的雜訊很大（同設計的南席在 r2、r3 各讀錯一次），三輪都沒有到凍結門檻。
