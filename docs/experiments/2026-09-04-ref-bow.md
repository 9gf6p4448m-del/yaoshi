### 誠實標註：射日神話的圖像參照沒找到，改用文獻

派工要的是「台灣原民射日神話的**木雕或版畫**」。在 Wikimedia Commons 用 `射日`／`Bunun`／`Paiwan wood carving`／`Atayal mural`／`原住民木雕` 五組關鍵詞各搜一輪（無 429、無需重試），**沒有任何一張是射日主題的木雕或版畫**——`射日` 只搜得到嘉義市的「射日塔」建築（一座抽象的塔，圖像上與神話無關）。
因此射日的部分改走派工允許的退路（「若只有文字則摘文獻」），文獻摘要見 §二末；圖像參照改用**同一個文化圈的祖靈木雕語彙**（`carve1.jpg`），它提供的是本隻真正需要的東西：**祖靈像的塊面、僵直正面性，以及那枚同心圓太陽紋**——後者正好是「焦黑落日」的造型來源。

## 二、每張一句

- **`deer2.jpg`**：台灣水鹿的角是**三叉**——角座上方一根短的眉叉往前上翹，主枝往**後上方掃出一道大弧**、到末端再分成兩根長叉往前上翹；角的顏色**分兩段**：靠根部粗糙、帶珍珠狀顆粒的**深紅褐**，末端被磨得發亮的**象牙白**。鹿身厚實、頸粗，頭小、吻長，耳大而外張。
- **`deer1.jpg`**：梅花鹿站姿的骨架比例——**軀幹短而窄、頸長且幾乎垂直、四條腿細長、頭小吻長、大耳外張**；白色斑點沿背側排成幾列。整體剪影是**高瘦的垂直物**，不是水平的長條，這正是祖靈段要的「修長、垂直線條主導」。
- **`bow1.jpg`**：圖注 `m` 的南台灣原住民獵弓是一把**單體木弓**——一根細長木身、弧度很淺、中段纏繩當握把、兩端各收成一個small 弦槽；弦是一條**繃得筆直的細線**，與弧形弓身之間夾出一個狹長的鏡片形。旁邊 `o` 的箭是細長竹桿配葉形／叉形鏃。**弓之所以一眼是弓，靠的是「弧」與「直弦」同時在場**——只有弧就只是一根彎木頭。
- **`carve1.jpg`**：魯凱祖先立像——**正面、僵直、左右對稱**，四肢貼著身體不做動勢；整根柱子是**塊面**鑿出來的，沒有一處圓滑過渡，風化成深褐並在剝落處露出暖赭；額頭正中一枚**同心圓紋**（外圈一圈放射狀鋸齒、中間一個凸起的圓心），頭比身體大得多，眼是細長杏形帶凸緣，嘴是一排鋸齒狀的牙，頸下與額上各有一道**規律的窄織紋帶**。

### 射日神話（文獻摘要，取代找不到的圖像）

布農族〈征伐太陽〉（中文維基百科「布農族征伐太陽傳說」條，引歐陽玉著、余錦虎譯《神話．祭儀．布農人》，晨星，2002）：太古天有二日，晝夜不分；一對父子攜**弓與箭**走了數十年到世界盡頭，躲在**山棕葉**的葉隙間才瞄得住，**射中太陽哥哥的右眼**；受傷的太陽自此失去厲光、變成月亮。後續段落另記：太陽墜落山上化為巨人，**賜予族人琉璃珠**。另有一段：太陽被射傷後另一顆太陽躲起來，大地全黑，直到**山羌**被石頭砸中頭而怒吼，才把太陽嚇回天上，山羌額上從此留下疤。

這三件事直接決定本隻的造型：
1. **「焦黑落日」不是一顆完整的太陽，是一顆被射瞎的太陽**——同心圓日輪中心要有一支**貫穿的箭**與一個熄掉的暗紅餘燼，不是金光四射。
2. **琉璃珠有神話出處**，不是硬套 ART_BIBLE——祖靈段的靛藍琉璃珠語言在這隻身上用得理直氣壯（做成眼與頸帶上的珠）。
3. **鹿科動物本來就在射日神話裡**（山羌吼聲喚回太陽）——「鹿角彎成弓的骨獸」不是憑空拼貼。

## 三、一眼特徵清單（造型必做項；★＝側視也看得見）

1. **★ 弓＝弧＋直弦**：一道跨過頭頂的大弧、兩端向下收，弧與弧端之間繃著一條**筆直**的弦，弧與弦之間夾出狹長鏡片形（`bow1` 圖注 `m`）。**沒有那條直弦就只是一對彎角**——這是本隻最不能省的一條。
2. **★ 鹿角分兩段色**：角基粗糙、深紅褐、帶一圈珍珠狀顆粒的角座；角尖打磨過、**象牙白**（`deer2` 實照）。另有一根短的**眉叉**從角座前緣往前上翹。
3. **★ 弦上懸著被射穿的焦黑落日**：一枚**同心圓**日輪（外圈一圈放射狀鋸齒、中心一個凸起圓心，形制取自 `carve1` 的額心太陽紋），通體焦黑，中心被一支箭貫穿，只剩一點暗紅餘燼（布農射日文獻：射中右眼、厲光盡失）。
4. **★ 鹿的體態**：軀幹短而窄、**頸長且近乎垂直**、四條腿細長、頭小吻長、大耳外張（`deer1`＋`deer2`）。整體剪影高瘦、垂直。
5. **★ 祖靈木雕的做工**：正面對稱、僵直不做動勢、**全塊面無圓滑過渡**的風化木／骨質感；頸上一道道**規律的窄織紋帶**；靛藍琉璃珠當眼（`carve1`）。

> 以上 5 條就是本隻的必做清單。M-A1 盲讀時 context-free 讀者列出的特徵須命中 ≥3 條（出貨下限），**目標 5/5**；沒讀出的登記到 `docs/experiments/2026-09-04-creature-gaps.md`。

## 四、參照 → 造型的翻譯（anyCreature 沒有貼圖，全部翻成幾何）

| 特徵 | 幾何做法 |
|---|---|
| 弓的大弧 | 兩條 `curve`（前肢／後肢各一，`mirrored` 左右各一對＝共 4 股，側視疊成一道厚弧），用 `rise`／`fall` 累積把航向掃過約 150°，兩端向下收 |
| 直弦 | 一條**不鏡射**的細 `curve`（`sides:4`、`r` 0.008），從前弧端拉到後弧端，中間不彎——直弦必須是直的，段間不給任何 `rise`/`fall`/`coil` |
| 角的兩段色 | 同一條 `curve` 做不到兩材質 → 拆成兩個部位：`antler_wood`（弧的前 2/3）＋`bone_tip`（末段短 `curve` 接在弧端上），交界處埋進彼此 |
| 珍珠狀角座 | 角基一顆短粗 `curve`（1 段、大 `r`、`sides:6`）當角座環 |
| 眉叉 | 一根短 `curve`，從角座前緣往前上，`taper` 收尖 |
| 同心圓焦黑日輪 | 中心一片 `fin` 正多邊形（凸 ✓）當日面；外圈 8 根短 `spike` 放射狀＝鋸齒；中心一顆小 `curve` 凸起＝餘燼（材質 `glow_sun`） |
| 貫穿的箭 | 一條細 `curve`（`bone_tip`），從日輪背面穿到正面，兩端都露出來 |
| 鹿的長頸 | 獨立 `neck` 鏈，近乎垂直、四節，`profile` 上細下粗 |
| 細長腿 | 前後腿 `profile` half-width ≤0.055，`sides:6`，末端 `paw` 做小蹄 |
| 頸上窄織紋帶 | 3 片薄 `fin` 環帶（`weave_band`／`bead_glass` 交錯），不用 `colors.arcs`（低 `sides` 會被角度格吸附，nail 報告 ⑥-2） |
| 靛藍琉璃珠眼 | `type:"eye"`，材質名 `eye`，色 `#4668c0`（同 shield 的祖靈靛藍） |
| 風化木塊面 | `build:"rigid"`＋每列 `exp ≥4.5`＋`smooth_angle 26`（17:30 模板規則） |
