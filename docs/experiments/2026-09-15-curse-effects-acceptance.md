# 詛咒品效果可讀性：修補驗收

2026-09-15，玩家提供兩張手機截圖：縛靈鎖詳情只寫「鎖魂之鏈」，市場的縛靈鎖／冥婚紅包也只有風味文案，未能得知實際減益。基準 aeb269a／公開 v0.57.11。

## 本輪固定範圍

1. 五種詛咒市場卡都說明持有後的機械效果，出價詳情提供完整作用與疊加規則；不可只顯示風味或「只算纏身」。
2. 紙紮夜戰依現行引擎：每件詛咒使持有者可出手紙紮每拍攻擊減 1；總攻擊不大於 0 時不出手。免疫纏身者不受此減益；不把作祟效果誤稱一般攻擊。
3. 帶 drain 的芭樂另列每夜末失去 1 壽命，免疫纏身不免持續失血；不得把其他四種的負 p 值誤寫成扣壽命或現行夜戰減攻量。
4. 一般夜、收祟夜與押寶夜皆可讀效果；收祟夜原禁止銷毀、押寶夜原不開標保持。出價／毒標對象／效果數值不改。
5. 852×393、安全區左右59／底21 的手機卡面不裁切；出價視窗可以捲動讀完整內容並操作確定。不縮字、不縮模型。
6. 真正 UI 缺文字的 RED → 修補後 GREEN，保留截圖，Astra 開圖檢查。既有 768 卡面檢查與適用單元測試通過；純文字／呈現變更 trace seeds1–20 相同。
7. 同步發布版本至 v0.57.12；沿用持續授權正常 push，核對公開資產與實載卡／詳情。CPU ratio、原 P4／M-A1、A1 真機最終驗收仍分開。

本輪補效果說明，不給五種詛咒新增差異化玩法。非紙紮模式依既有戰力 p 與 drain 顯示，不擅自改規則資料。
