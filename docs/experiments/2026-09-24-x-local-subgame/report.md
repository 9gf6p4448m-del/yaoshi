## 解讀

「得標免費」下，H 最接近支配的選項，在最壞的對手組合裡仍會少拿一整件 X（×1.0 遺憾恰好等於 X 的估值）：對手出高價搶 X 時，最佳選擇是押命單標 X；沒人搶時，最佳選擇是兩件同標。多物件、多金額的密封拍賣裡，最佳回應本來就高度依賴對手，所以單夜支配檢查（不論精確或 ε＝1）連明顯壞掉的鏈都抓不到。

這表示 GAME_DESIGN 六之四的支配窮舉，對「二選一」型異事有效，**對拍賣型連鎖沒有鑑別力**。這也是 L1 水陸 README 第 28 行指出的「購買行動網格未定義」問題背後的實質原因。
