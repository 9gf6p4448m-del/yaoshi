# 席位之手＋後景人影：凍結驗收 v1.0

日期：2026-10-01。依據：`docs/proposals/2026-09-30-seat-hands-silhouettes.md` §7、§8.1（使用者 2026-10-01「其他按照建議」＝照提案原樣凍結）。
基準 SHA：`68d25790`（v0.59.4）。凍結後要改任何一條，先寫「原標準錯在哪、為什麼現在才知道」並取得使用者針對該條的明確同意（02 §2.1）。

## 範圍
- 階段一（原型閘）：單隻右手、帶骨 GLB、≤1,500 三角形、三姿勢截圖，只做 #A。
- 階段二：動作／四席／兩版面／收驚婆、當鋪、獵人三角色（#B、#C、#D）。
- 階段三：北／西／東後景人影（#E）。
- 斷手書生、其餘 6 角色、顯靈不在本凍結範圍。

## 條件

**#A 退場閘（階段一，單手原型）**
- A1 參照：`tools/anyCreature/out/ref/hand/` 內每種姿勢（推錢柱、掌心朝下按住、五指扒攏）≥2 張，並有 `docs/experiments/<日期>-ref-hand.md` 列 3～5 條一眼特徵。
- A2 面數：單手 ≤1,500 三角形（原型）；骨架約 20～24 根；GLB 走 `creature-figures.js`／`skeleton-share.js` 管線，頂點色、無貼圖。
- A3 盲讀：≥6 位 fresh 讀者看「手放在桌面截圖」的圖，三問：像真手／像塑膠人偶／跟紙紮妖放一起突不突兀。判「突兀」過半（≥4/6）＝閘門紅，停下回報使用者，不進階段二。
  - 能讓此條變紅的實作：把手做成平滑 Q 版或塑膠感、色調與桌面脫節。

**#B 硬指標（階段二結束時）**
- B1 draw call 增量 ≤ 席數（≤4）＋人影（≤3）；每隻手 ≤2,500 三角形（使用者 D1 上限）；每個人影 ≤200。
- B2 A1 相對效能 gate（perf32／perf128）不得由綠轉紅；紅了先回報，不得砍面數或放寬 gate。
- B3 `tests/tools/trace-eq.mjs` 對 `68d25790` equal:true。
- B4 取景矩陣（1599）不變差；全套測試相對基準紅燈清單無新增紅。

**#C 行為**
- C1 推／拍／收三動作：指尖不穿錢柱與令牌（取樣檢查）；收手後不遮 HUD；不進 `tray.hitTest`（U2）。
- C2 `P`／`L` 兩版面都驗。
- C3 跳過與縮時：結算不變；跳過時手與錢直接到結束姿態。
- C4 決定性：不耗亂數（Math.random 計數 0）；同事件序列產生同手勢序列。
- C5 同席同格重複出價＝覆寫，不疊兩隻手；熱座清場即收。
- C6 令牌落地那一幀仍由令牌發 `ys:mark-slam`。
- 每條各附「改壞後會變紅」的突變驗證。

**#D 辨識**
- D1 收驚婆／當鋪／獵人三角色：6 位讀者看桌面截圖，「這是誰的手」靠袖口＋配件答對 ≥5/6。
- D2 同批再問「像塑膠人偶／像真手／跟紙紮妖突不突兀」，結果照實記。

**#E 人影（階段三）**
- E1 有體積、非平面貼片，每個 ≤200 三角形；落在掏空窗內，不蓋托盤、拍品、HUD 安全區。
- E2 對決模式隨 group 隱藏；自動退鏡行為不變（取景檢查重跑）。

**#F 回報口徑**
- 結果只寫「觀察到／未觀察到／未驗證」，不宣稱大作水準。使用者在 iPhone 真機簽收後才談部署。
