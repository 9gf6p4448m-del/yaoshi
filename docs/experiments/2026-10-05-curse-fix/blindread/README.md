## 受試者原答（詛咒兩張摘要；干擾題 r1–r3 幾乎都答「看不出來」）
- r1 seq-1（西塞東）：被動的東西看不清，手從下方偏右伸來「像東或南」，「東（或南）拿走？」，丙偏甲，低。
- r1 seq-3（北塞南）：紅白小物最後在南席前（中），「手先從右側伸進來，又有一隻手從左下方伸到紅色物件上方，像抓住壓住」，「南拿走」，偏甲，低到中。
- r2 clip-2（北塞南）：紅包從遠端移到近端停在南前；「蒼白帶光環的手從北伸下來壓著紅包，棕色手從南手心向上托在下方」→「北 塞給 南」，乙，中低（也可能是南拿走）。
- r2 clip-4（西塞東）：紅盒最後在東；「米白袖口的手從左上（北或西）伸來碰著紅盒往右帶，棕色長手從右下橫伸」→「北 或 西 塞給 東」，乙，低。
- r3 film-1（北塞南）：紅衣東西最後到南席前；「帶金色光圈的淺色手從遠端伸下來壓住、深褐色手從近端托著接著」→「我猜是北席塞給南席」，乙，中低（若近端手主導也可能是甲）。
- r3 film-3（西塞東）：紅色方形物最後「偏東／偏南」；「帶袖口的手臂從左（西）壓在上方、褐色長手臂從右（東）橫過桌面停在下方」→「我猜是西席塞給東席」，丙勉強偏乙，低。

## 讀不出來的原因（受試者依據歸納，未驗證的假設）
1. 受害者的手在符紙堆到之前就先伸到桌心平放（A 設計：伸出、想縮又被逼回），連拍上「受害者主動伸手到東西底下」容易被讀成「他去拿」；這段是 A 的既有設計，本卷不准動。
2. 施放者的手臂從自己席位那側進場只佔推送前 0.26 秒，西席手臂在鏡頭裡從畫面左上進來，與北席不易分。
3. 符紙堆落定後只停約 0.64 秒就依既有終態隱藏（治具量測 1650ms 起 item.hidden）；受試者在最後幾格指認的紅色物件是否就是符紙堆，未驗證。
