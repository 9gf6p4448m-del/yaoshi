# 驗收凍結：妖市高光轉場卷（2026-09-15）

> 依據：`docs/ROADMAP_V2.md` §3.2 與 `docs/proposals/2026-09-10-roadmap-v2-review.md` §12；路線順序由 `docs/proposals/2026-09-12-roadmap-v2-progress.md` §6 定為上桌卷後的下一卷。

## 範圍

- 純演出層新增三種高光：誅心、借刀、命懸一線。
- 判定只能讀既有的 `S.marks`、本夜拍賣／死亡紀錄與 `S.history`；不得改拍賣、戰鬥、壽命、RNG 或 AI。
- 觸發點限定在真人頁的開標後、夜戰結束後、局末結果頁；`simulate()` 與 `playPolicyGame()` 不得執行任何轉場。

## 驗收條件

1. 以單一 `CUTS` 表定義三種轉場與其純讀取判定；每局每種最多播放一次。
2. 誅心：玩家盯上的拍品被低價得標，或其餘玩家未競標，才可在揭盅後觸發。
3. 借刀：毒標目標在同夜死亡，才可在夜戰結束後觸發。
4. 命懸一線：最終第一名曾有壽命 `<=5`，才可在局末觸發。
5. 所有轉場均提供 reduced-motion 靜態／淡入版本；不切鏡、不震動。
6. `trace-eq` 與既有賽局測試結果不得因本卷改變；轉場沒有新 3D 資產、沒有新 draw call。

## 暫不包含

- 「連鎖破陣」：依賴尚未開卷的法寶連鎖系統。
- 連鎖、幽靈 PVP、夜行錄、妖幣、天梯與即時連線。
