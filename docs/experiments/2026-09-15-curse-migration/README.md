# v0.57.12 詛咒差異化、造型與取消戰力

狀態：本機實作與程式測試完成；最終手機瀏覽器驗證進行中，尚未發布。

## 玩家看到的改變

原市場五件詛咒共用紙堆與紫火，沒有各自模型。本輪沿 A「廟埕暗桌・紙紮顯靈」製作六種實物輪廓，保留共用紙材與火焰。王船煞只從事件入袋，造型圖中的王船為合成展示，沒有把它加入普通市場。

|詛咒|每件的效果|造型|
|---|---|---|
|冥婚紅包|本夜有得標才在夜末付 1 壽命禮金|紅色封口紙包|
|魔神仔的芭樂|每夜末失 1 壽命|帶葉芭樂|
|抓交替水符|每戰首次折損後，牽連另一隻存活紙紮受 1 傷害|彎折藍符|
|縛靈鎖|第 1 拍最高基礎攻擊前鋒攻擊 −2|鎖頭與鎖環|
|白虎煞|戰敗額外失 1 壽命，仍套用法寶減傷|白紙虎面|
|王船煞|第 1 拍最高血量紙紮失 1 血，最低留 1|翹首紙船|

完整目標、疊加、淨化與結算順序見 [凍結規格](acceptance.md)。取消原本所有詛咒共同扣攻，四件純舊戰力能力退出正式模式，但其紙紮招式保留。自動選敵改按壽命，獵人按開戰前紙紮隻數判斷強敵。行情僅保留為心願、信譽等市場規則的參考價，出價面板明示數字。

全 36 件說明見 [覆蓋表](coverage.md)。舊文案卷的 35 件／65 測試與 trace 相等為改規則前歷史證據，不作本卷驗收。
