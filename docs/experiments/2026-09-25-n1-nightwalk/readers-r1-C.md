# 讀者 C（fresh sonnet，r1）原文回報

第一章（破廟逢青面）
(a) 青面攤主本是廟口秤頭缺斤短兩的賣香燭攤販，大水沖斷山路後不肯收攤，死後變成專搶客人手上那系貨物（用命換命）的怪；主角撐到天光、壽命比他多，他第一次把秤頭擺平放人下山。
(b) 是。破廟香火、秤頭作弊、命換命、台語口白（「少年仔」「毋免錢」）都很有台灣廟埕怪談味。
(c) 「你看中哪一系的貨，他就偏偏跟你搶哪一系」——「系」是遊戲機制詞，沒玩過遊戲的讀者會愣一下，但不影響故事理解。

第二章（招魂嶺收驚婆）
(a) 收驚婆本是幫山下受驚囡仔喊魂的老婆婆，喊到米甕見底連自己的魂都喊散了；她整夜不出手、等大貨上桌才一次收走，主角把該湊的都湊齊後，她把僅剩一粒米的米碗推給主角，說下次驚著要自己喊魂。
(b) 是。收驚儀式（米碗、舊衫、喊名）描寫細膩，台語對白自然道地。
(c) 「這一夜的妖市，貨會兩件兩件地認主」這句規則性描述稍抽象，要配合遊戲機制才完全懂，但故事本身讀得通。

第三章（荒塚紅衣婆婆）
(a) 紅衣婆婆生前替人縫壽衣，自己那件被偷走換了錢，死時只能穿嫁衣下葬，死後把恩怨全記在衣角上；主角沒佔她便宜，她把紅衫脫下疊好放墳頭，說「帳清了」。
(b) 是。荒塚無名墳、紅衣意象、因果記帳的設定完全是台灣志怪套路。
(c) 無，這章敘事最順、沒有卡頓的詞句。

(d) 簡體字或大陸用語：無。全篇繁體中文，且用了大量台灣本土台語詞（毋免、囡仔、家己、袂、攏、彼、矣等），語感道地，沒有大陸用語痕跡。
