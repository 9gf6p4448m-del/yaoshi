**side W/H 兩種量法都列出來的理由**：`silmetrics` 是把 48px 剪影點陣化後量的，`1.00 → 1.01` 落在它的量化雜訊裡；`bow` 本輪的全高是**整份 spec 等比縮放**得到的，等比縮放在數學上不改變任何比值，所以另附 judge `whole.size` 的精算值（`1.2522/1.21 = 1.03489` vs 基準 `1.1555/1.115 = 1.03632`）作為「沒有變差」的硬證據。

**`ring_step` 據實揭露一處放寬**：`raincoat` 的 `hood` 由 **0.014 → 0.016**。原因是把帽兜 `sides` 20→9 並改成塌陷式 profile 之後，編譯器的 `profile slope` WARN 由 3B 的既有警告惡化到 1.06（「rings are crowded … flips triangles once it bends」），編譯器自己的建議就是 Raise ring_step；調到 0.016 後 slope 回到 0.88。`ring_step` 不在凍結檔 19:10 訂的 faceted 四項（build／faceted／exp／smooth_angle）之內，3B 報告也記為「可選」，但它是往粗的方向動，所以在這裡寫明，不藏在表格裡。`bow` 的 `ring_step` 全部乘上同一個縮放係數 1.0852，環數與基準完全相同。

1. **★★「一圈放射狀的東西」同時是太陽與齒輪的定義，形狀分不開的東西要靠亮暗分布分。**

2. **★★ 拆掉否定型條款的訊號，會把肯定型條款一起拆掉。**
   第 1 輪一次動了三件（軸孔／圓盤形狀／火舌繞不繞滿一圈），齒輪歸零，但太陽也從 3/3 掉到 1/3（三位改讀成「火焰／烈焰」）。兩條條款共用同一塊幾何時，**一次只准動一件**，否則歸不出是哪一件在起作用。本卷第 2 輪就是靠「只把圓盤與繞滿一圈收回來、暗心不收」才把兩者拆開的。
