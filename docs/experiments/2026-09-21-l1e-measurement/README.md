# L1e 探索量測工具

承接 v0.57.37 三組連攜候選，使用者要求繼續實作。本卷只新增開發用量測工具與測試，不改遊戲數值／UI，不重做水陸或 A3 已驗證項目。目的是讓連攜對照能重跑、知道每個百分比的分母，並阻止工具把未完整定義的正式閘門顯示為通過。

先讀 [執行前契約](contract.md)。原正式標準仍為 [L1 計畫](../../../plans/2026-09-21-l1-chains.md) 的六之四、n≥10000、追連攜相對 splitter −8～+5pp、持有者 +3～+10pp。

## 工具量的是什麼

七臂使用同一組種子與實際 `playPolicyGame`：splitter 基準，加上水陸／千眼／雙虎各自的追材料策略及單組效果歸零對照。CFG 不變，座位0固定青面攤主；其他玩家依原引擎生成。無頭執行不涉及練習入口的預置材料或固定 AI。

新追法 `target-chaser-v1` 是一個明確、可反駁的探索策略，不是假定最強玩法：在 splitter 標單上優先補指定材料、保守加價2，受到原預算／保守上限／筆數限制。只讀本人的材料與當夜公開市集。單組歸零保留配方與AI追件動機，移除那一組的效果及融合部隊，其他組不改。共用 CHAINS 的效果停用涵蓋全四席，所以此比較不是單獨移除座位0能力的效果。

完整逐局資料記錄在 raw JSONL，摘要包含種子範圍、角色、CFG、source/tool hash及git版本；配對差按相同種子逐局計算，缺種子／重複種子拒絕計算。零持有局的條件勝率為 null，不呈現為0%。

## 正式口徑仍缺的部分

| 項目 | 原要求 | 本工具限制 |
|---|---|---|
| 追連攜策略 | 固定正式策略再比較splitter | 目前只實作命名的探索追法，不代表最優策略或已裁正式策略池 |
| H9持有者 | 原傳說runner以「至少一位holder的局」作分母，看贏家是否為holder；各臂分別條件化 | 本工具holder限定座位0局末仍持有材料，**不同於原H9**；數字不套正式持有者帶 |
| 效果歸零 | 明列開關與配對 | 每次只停用目標一組，保留配方/AI加價；不是清空CHAINS |
| 千眼情報價值 | 使用者實際可以利用預告與標額 | splitter與本追法不使用這些情報，所以零差異不能推論千眼無價值 |
| 六之四 | 對定義好的局面與玩家選項窮舉收益，排除弱優勢／free lunch | 原analyzeEvent處理靜態收益矩陣；跨夜連攜的狀態、出價格點、收益時間點仍未凍結，工具不冒充整局窮舉 |
| 樣本 | 正式每策略n≥10000 | 本輪固定1..200只檢驗工具和觀察取得率；即使指定n10000也不會自動放行正式閘門 |

同種子效果開／關的軌跡可以因規則改變而分岔；配對勝率差是此模擬設計下的比較。兩臂局末持有者可能是不同樣本，條件勝率差不得稱為因果增益。

原始定義參照：`tests/tools/legend-gate.mjs` H1/H9、`docs/GAME_DESIGN.md` 六之四、`docs/proposals/2026-09-10-roadmap-v2-review.md` §2。舊 `balance.mjs` 硬編主工作樹且量夜規，本卷不沿用它的目標路徑或標籤。
