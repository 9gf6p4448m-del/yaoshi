## 驗收條件（凍結；改動走 02 §2.1）
- **R-1 列陣不交錯**：`lineup` 模式 8v8／6v6／4v4／3v3 四組，`gap ≥ 0.30`（兩側腳印外緣沿畫面右方向的距離）。
- **R-2 不踩桌緣**：同四組每尊 `r ≤ 2.20`（桌面半徑 3.4、八邊形內切 3.14；2.2 留出腳印與剪影的視覺餘裕），`offTable = 0`。
- **R-3 同側不疊**：同四組 `minPair ≥ 0.50`。
- **R-4 小編制不變**：1v1、2v2、2v1 三組每尊世界座標與 `fae1eec` 同機同視窗實測值差 <1e-3（OFF 退路與 v0.30 逐項相同的承諾不動）。
- **C-1 字幕寫出誰丟＋做了什麼**：每筆 trait 事件當下 `#duelMove` 含「出招方玩家名」「法寶名」「招名」與 `TRAITS[trId].desc`（第二行小字），元素帶出招方系別 class（`f-zuling|f-xianghuo|f-yinqi`）與側別 class（`side-A|side-B`）。量法：duel-drive 錄音機在 `ys:fx-trait` 派送當下讀 `#duelMove`（同步事件，字幕已寫入）；同種子 4 場所有 trait 事件 100% 命中；`--no3d` 同樣命中（字幕不依賴 3D）。
- **C-2 出招側打光**：3D 舞台接下招式時，戲台燈組往出招方質心方向位移 ≥0.5 世界單位（≤150ms 內到位），招式結束（900ms）後 ≤150ms 回到 (0, 0.15, 0)；SKIP／cancel 立刻回位。量法：traitfx-preview 暴露 `rigPos()`，driver 每幀記錄、驗 27 套（`focus` 判定）。無 3D 不受影響。
- **C-3 不退步**：`traitfx-drive` 原編制／滿編／reduced／throw／cancel 全綠；同種子 4 場 duel-drive：招式數 1/2/1/3、traitFig 7、pageerror 0、每場時長 ≤ `bl3-v033-seed` 對應場 +80ms。
- **C-4 直式 390px 高不裁字**：字幕多一行後 `#duel` 的 `scrollHeight ≤ clientHeight`（既有 layout 承諾），量法：duel-drive 錄音機在 trait 事件當下讀 `#duel` 兩值。
- **D 送達**：VERSION→0.34、push 後 `git log origin/main -1`；一輪 fresh opus 冷讀 diff（小卷只一輪，CRITICAL/HIGH 全修）。

不在本卷：鏡頭（後處理卷）、燒毀規則（使用者裁定甲維持）、慢動作（裁定不做）、`PAPERWAR_ON` 預設值。
