# 驗收條件（凍結）— 席位之手「中等寫實」v0.59.7

基準＝origin/main 95f621db（線上 v0.59.6）。使用者 2026-10-02 看過對照示意圖（phase2-mock/hand-realism/contact-hands.jpg）裁定「中等寫實很棒，以這個方向」。
方向：寫實的比例與骨架（指節、指甲、皮膚微光與厚度）＋紙紮廟埕風材質，不追照片級；不可愛、古老威嚴。
本卷範圍：所有角色的手本體套寫實材質與縮放；收驚婆／獵人／當鋪三個身分變體升級。其餘角色的「身分變體」不在本卷（併入後續畫面升級卷）。不動引擎、不動鏡頭。
凍結後任何放寬（門檻、案例集、量測範圍、治具）照 02 §2.1：先寫原標準錯在哪，取得使用者針對該條的明確同意。加嚴自行記錄。

## 條件（每條都要貼實測輸出；「會讓它變紅的實作」附在括號）
1. **尺寸**：每個有手的角色，指根骨距（同示意圖量法：凍結同一幀、蒙皮骨架、世界單位）≤ 基準 0.2014 的 0.70 倍；三個變體實測須落在 0.50–0.70 倍。（紅：不縮放＝1.0；縮過頭 <0.50 也紅）
2. **全角色覆蓋**：ROLES 表所有帶手的角色，執行期查驗 100% 使用寫實材質（列出角色名單與每個的材質 id，N 要數出來，不憑印象）。（紅：只改三個變體、其餘預設手沒套）
3. **身分可辨**：收驚婆／獵人／當鋪各一張同鏡頭特寫，去掉標籤、隨機排列，交給沒有對話史的 fresh agent，只問「這三隻手各是什麼樣的人」並請它配對給定的三句身分描述（老皺乾／粗有繭疤／蒼白修長），配對 3/3 正確；亂數排列重做一次仍 3/3（隨機猜中機率 1/6）。（紅：三隻手只差膚色濾鏡）
4. **銅錢比例**：844×390 與 1280×720 遊戲視角，一疊銅錢的投影高度 < 同畫面手包圍盒投影高度（嚴格小於）；兩個視口、三個角色都量，貼數值。（紅：手縮小後銅錢仍與手同高以上；改法限縮銅錢可讀性視覺比例須同時過下一條）
5. **既有避讓不退步**：信物避讓／伸入界線／1599 取景矩陣，以與基準同一份治具、同一組格子重跑，0 新增紅格；有紅格逐格列出並判是產品問題還是量測問題，不得以調門檻消紅。
6. **效能不退步（桌機，標明量測位置＝本機 Chromium，不代表 iPhone）**：用示意圖同一支 perf-diag，手可見／收掉的每秒渲染次數比值 ≥ 基準比值（0.816）的 0.95 倍；每隻手三角面 ≤ 6,500；draw call 每手仍為 1。iPhone 實機未驗須在回報明寫「iPhone 未驗」。
7. **引擎零改**：trace(1..20) 與 95f621db 逐位元組相等；全套測試結果與基準相同（基準先在 95f621db 跑一次記錄）；兩種視口 console 0 error。（紅：任何引擎／規則檔改動）
8. **版本與送達**：index.html 的 VERSION／RELEASE_VERSION 與帶 ?v= 的資源版本改為 0.59.7；推 main 後貼 `git log origin/main -1`、Pages 狀態、curl 線上 VERSION 與新 js 檔回 200。
9. **使用者簽收圖**：實作完成後在遊戲真實視角產出與示意圖同格式的最終對照圖（現況 vs 新版，三角色，844 與 1280），傳給使用者；使用者以 iPhone 真機看過前不宣稱「質感通過」。

## 已知並明示的限制（不算違反）
- 皮膚為程式生成，無外部貼圖（hand_r.glb 無 UV）。
- 掌紋不做（掌心朝下看不到）。
- 當鋪「修長」以手指變細達成，不改骨長。
- 844 寬時手約 50–60px，質感在手機視角只靠尺寸／膚色／指粗輪廓；質感判讀看特寫格。

## 增補（2026-10-02，使用者回饋；屬加嚴，不放寬任何既有條件）
使用者看示意圖後回饋：配件（收驚婆的紅線與珠子等）也不夠寫實——示意圖裡紅線是扁平色帶、珠子是多面體，與手本體的寫實度脫節。裁定：配件與手本體同一寫實標準（中等寫實）。
10. **配件寫實**（收驚婆紅線＋木珠、獵人皮護腕＋鉚釘、當鋪翡翠戒指＋金邊袖口）：
   a. 紅線為圓截面的繩狀幾何（不是扁平色帶），繞腕 ≥2 圈且圈距／鬆緊有輕微不規則；可見線徑與捻股／毛邊質感（特寫格）。
   b. 木珠為球形：特寫剪影圓度（4π·面積／周長²）≥ 0.85，珠徑有約 ±10–15% 的變化，有木紋或不均勻色，珠間可見線。
   c. 獵人鉚釘、當鋪戒指寶石同標準：剪影無明顯多面體稜角（圓度同上或有量測依據的等價量），寶石有高光。
   d. 盲讀：去標籤特寫交給沒有對話史的 fresh agent，只問「紅色的是什麼材質、圓的是什麼、金屬釘是什麼」，須答出線／繩、木珠或念珠、鉚釘（語意同義可）；舊版（95f621db）與示意版各跑同一盲讀，記錄其結果。
   （鑑別力：先在 95f621db 與示意版量圓度；若兩者已 ≥0.85，本條的 b 無鑑別力，停手回報，不要自行換量法。紅：沿用示意版的扁平色帶與多面體珠。）
   縮放後配件須同比縮小並維持可辨，不得因此被手遮住或在 844 視角看不到。

## 增補 2（2026-10-02，使用者質疑；屬加嚴）
使用者指出：手縮小後會變成「只看到一隻斷手」（示意圖右欄收驚婆／當鋪確實是手＋袖口浮在桌上，袖口後端露出空心開口，現況版則是前臂延伸出畫面）。裁定：不做軀幹（併入後續畫面升級卷的取景重設計），但手必須連著手臂，不得懸空。
11. **手臂連續**：三個變體加預設手，在 844×390 與 1280×720 遊戲視角、整局所有夜與出價／揭盅階段的取樣幀，手腕→袖口→前臂必須連續延伸到畫面邊緣或被桌緣／其他不透明物遮住，畫面內不得看得到袖口或前臂的後端開口（量法：袖／前臂網格後端頂點投影到畫面，不在畫面外、也不被深度遮擋＝紅；貼量測腳本與逐幀結果）。縮小手的同時前臂與袖子長度須按需要延長，不得因縮放而變短。（紅：只縮放手、不延長前臂＝示意圖現況。）
