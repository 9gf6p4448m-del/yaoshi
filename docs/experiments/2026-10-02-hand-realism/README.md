## 改了什麼（產品）
- `js/hand-realism.js`：寫實皮膚（一份共用材質，四種手參數在 uniform 陣列）、手部 Loop 細分（只細分 z≥−0.45 的手＋袖口）、依角色重塑、配件權重重綁（硬配件整顆一組）、**袖管（修訂 4）**：每次畫之前（onBeforeRender，拿到這一次真正在畫的相機）把袖管重鋪成「袖口→最近畫面邊緣」的二次曲線——候選四邊依「曲線投影壓過拍品外框的點數」選最少者（不橫過拍品前方），罰「迎向鏡頭」的邊；目標點在邊外 1.0 NDC，最後一圈不透明截面若還有頂點在畫面內就沿同一視線推遠；控制點上拱 0.1 免擦錢／令牌；末段漸暗、最後一圈（畫面外）漸隱。袖管綁 Elbow 骨（姿勢從不轉它），CPU 寫的座標＝畫面上的座標；相機、手、袖口都沒變就不重鋪，重鋪只上傳袖管那一段。
- `js/hand-motion.js`：`HAND.USER_SCALE`（預設 1）、**`HAND.REAL_ON`（總開關，預設 true）**；`buildRoleGeometry(..., {real})`：real=false 時輸出 v0.59.6 原樣配件（含原八角錢 `coin8`），與 95f621db 逐值相同；紅繩改沿每個方位角找原手表面實際半徑（貼腕不浮）、截面 7 邊、繞 2.25 圈；當鋪金滾邊改金屬類別；director 支援每席碰撞骨架、解算支援 pad 外擴（現行未用，預設 0）。
- `js/table-hands.js`：寫實開／關兩條分支（`?handreal=0`）；每席一份寫實幾何（袖管各自重鋪）、碰撞取樣依種類（取全部手＋配件頂點，不含袖管）；拍品外框每 6 幀算一次。`js/table-tray.js`：把拍品節點交給手（袖管避讓用）。
- `index.html`：版本字串 4 處。
