## 改了什麼（產品）

- `js/hand-realism.js`（新）：寫實皮膚材質（一份共用材質、四種手參數放 uniform 陣列；指甲、指節紋、肌腱、靜脈、老人斑、繭、疤、紙纖維、假次表面散射；配件另畫繩股／木紋／金屬）、手部 Loop 細分（只細分 z≥−0.45 的手＋袖口，前臂不細分，粗細交界扇形補洞）、依角色重塑指粗／指節／手背、前臂換成程式生成袖管（延伸到世界長 8、依席抬升、末段畫面外淡出）、配件權重重綁（硬配件整顆一組權重）。
- `js/hand-motion.js`：`HAND.USER_SCALE`（預設 1，全角色唯一縮放旋鈕；網址 `?handscale=` 可試玩覆寫）；director 接受每席倍率與每席碰撞取樣骨架；紅線改圓截面繩（繞腕 2.25 圈、圈距／鬆緊抖動）、木珠改 UV 球（珠徑 ±13%、串在細紅繩上）、獵人護腕加 6 顆圓頂鉚釘、當鋪方孔錢外緣 8→16 段；配件材質類別屬性。
- `js/table-hands.js`：所有角色（含預設手）都走寫實幾何＋共用材質；每種手（×每席前臂彎法）快取一份幾何與碰撞骨架（取樣＝畫面上這隻手的全部頂點）。
- `index.html`：只改版本字串（4 處）。`tests/hand-fixture.mjs`：多換一個 data: 模組（hand-realism.js）。`tests/ui-hierarchy.test.mjs`：版本釘 0.59.6→0.59.7（照 v0.59.6 前例 `933f1de1`）。
- 治具（新）：`tests/tools/hand-realism-measure.mjs`（條件 1/2/4）、`tests/tools/hand-arm-continuity.mjs`（條件 11）、`tests/tools/hand-acc-roundness.mjs`（條件 10b/c）；本目錄 `tools/acc-follow-check.mjs`、`tools/live-cost-real.mjs`（診斷）。
