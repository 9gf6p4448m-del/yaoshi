## 二、從照片上實際看到的東西（觀察筆記，非清單）

- `boar-side-01`：頭是一根從肩往前收的長楔形，越往前越窄，末端戛然截斷成一片**平的圓盤鼻**（鼻孔在盤面上）。眼睛極小、位置很高又很靠後，幾乎貼在耳朵前面。耳直立、耳緣一圈黑色長毛。**沒有脖子**——後腦直接接到一團隆起的肩，肩是全身最高點。全身覆蓋粗硬的斑駁毛，肩背一線的毛明顯比別處長而且**往上豎**。前肢深色、短、粗。
- `boar-head-tusks`：四根牙。**外側長的一對是下犬齒**——細長、象牙白、彎成一道大 C，從根往外往上掃，尖端朝上；根部帶褐斑。**內側短的一對是上犬齒**——粗、短、彎得更兇，幾乎捲成一個圈，根部褐色明顯，尖端朝上朝後。整體斷面不是圓的，是帶稜的。
- `tusk-armlet-tsou-01`：兩根牙尖對尖圍成一個近乎閉合的環，環的開口與接合處用繩纏死；紅色羽毛從接合處炸出來，紅／黃布條垂下。**「環」本身就是這件器物的主形。**
- `tusk-necklace-sarawak-01`：一個硬環，環身正面鋪一列橫躺的貝殼／骨片，**環外緣整圈插著向外放射的彎牙**（每根都像小尖刺、根褐尖白），牙與牙之間是一串串深藍黑／白／紅的珠子；環的頂端接口纏著一段紅布。

## 三、一眼特徵必做清單（★ 凍結，寫 JSON 前定稿，此後一條不得增刪改）

1. **長楔形拱鼻頭 ＋ 平截圓盤鼻**：頭從肩往前收成一根長楔，末端截斷成一片平的圓盤豬鼻；眼睛小、位置高且靠後（近耳根），不是圓大眼。
2. **野豬體型**：肩背隆起成全身最高的肩峰，往後往下斜到較低的臀；頸粗到幾乎沒有脖子；四肢粗短。
3. **倒豎的背鬃脊**：從後腦沿頸背到肩背，一列明顯比體毛長、**尖端朝上豎起**的硬鬃，是全身唯一的高頻尖銳輪廓帶。（＝主色祖靈金的落點）
4. **外翻獠牙**：吻部兩側各一根象牙白的獠牙，**由下往外往上彎成 C 形勾、尖端朝上外露於吻的輪廓之外**，牙根帶褐；另有一對更短更捲的上牙。（＝招牌剪影）
5. **骨牙項圈**：頸上一圈環，環身鑲一列橫躺的骨／貝片，環外緣**放射出一整列向外的小彎牙**，牙間夾深色珠列，接口處纏紅繩。

## 四、氣質口徑（祖靈，非陰氣）

ART_BIBLE §2：祖靈＝被繼承的古老神獸／圖騰，材質是獸骨、風化木、皮革、藤編、琉璃珠；氣質是古老、莊嚴、山林的獸性威嚴。
xianji 卷教訓：**冷光殘留與垂頭姿態會把祖靈拉向陰氣**。本隻對應處置：
- 發光只用暖色（金／琥珀）系，不用青綠或冷藍。
- 姿態＝**吻端上抬**（獠牙朝上頂的預備姿），不是垂頭嗅地；肩峰仍是最高點（那是野豬解剖事實），但頭是端平、鼻尖朝上。
- 不用殘缺、腐爛、裂嘴、空洞眼（ART_BIBLE §2「不用」）。
