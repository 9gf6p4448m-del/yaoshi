## 未解清單（帶到後續）

1. **「低多邊形無貼圖讀不出物件身分」同族四題**：福壽綿長「燈」0/6、大士爺「鏡」0/6、紅帽「猴臉」0/4、拼板舟划手被讀成立柱。共同根因：碗／盤／臉這類靠凹凸與材質的身分訊號，幾何＋頂點色做不出來。候選出路：反光／自發光材質、法線貼花卷（`2026-09-06` 貼花小卷已有前例）、或簽為引擎限制。
2. **P4 對象語彙**：8 支未過中只重讀 wardRegen1（5/18）；「我方單一」的腳下光被 §A9 守衛擋住只能用胸口豎環，需要重設計對象語彙（含 swarmHalfSplash、hauntLost 本支重讀）。
3. **滿編 8v8 讀者指認**（凍結 #4 第三項）三件資產未做。
4. 治具：`curse-migration.test.mjs` 對造型零鑑別力；`table-framing-check.mjs` 無 `--port`、launch 跑序不穩；`a2-sheet.mjs` 不支援傳說尊與詛咒（後者已另做 `a2-curse-sheet.mjs`）。
