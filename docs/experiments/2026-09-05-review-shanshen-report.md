## ⑨ 沒做到／誠實條

1. **第 2 輪一次動了兩件事（扶壁上抬＋鞍部縮小下沉），第 3 輪只動一件。** 所以「扶壁」與「鞍部」對甲殼主詞各自的貢獻分不開，只知道兩件合起來把 2/3 壓到 1/3。這是為了在 3 輪額度內收斂做的取捨，攤在這裡。
2. **原裁定只授權兩個旋鈕（橋洞、岩階），本卷多動了扶壁與鞍部。** 理由：第 1 輪三位裡有一位逐字寫「側腹裝甲……灰色圓潤護甲」，加上 4B 補讀六位裡另外兩位也寫過同一族措辭，這是造成 R3 不過的具體、可修的原因；R3（甲殼 ≤1/3）是凍結的驗收條件，扶壁與鞍部是達成手段而不是門檻鬆動。**驗收條件一格未改。** 若主對話認為超出授權，回退方式是把 `BUTUP`／`SADDLE`／`SADDLEDROP` 三個量歸零重編（改動集中在 `shanshen.json` 的 `parts` 中 `_c` 含「扶壁」與「鞍部」的 24 個零件）。
3. **r13（岩盤／上板／苔毯平面 ×0.80）做了但撤掉**：肉眼與機械值都看不出差別，依 Surgical Changes 不出貨。
