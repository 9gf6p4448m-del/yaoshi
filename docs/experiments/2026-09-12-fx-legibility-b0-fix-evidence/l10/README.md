  `fontBad`＝`kindBad`＝`hueBad`＝0。這一條沒有雜訊問題。
- **R2 seed 1（duels=8）**：本批 🔴🔴、基準也 🔴 ⇒ **基準本來就過不了**，不是本批弄壞的。
- **R2 seed 3（duels=8）**：兩樹都 0 個可判樣本（fail-closed），無資訊。
- **R2 seed 3（duels=20，固定條件各連跑 5 次）**：本批 🟢2／🔴3、基準 🟢4／🔴1。
  **兩棵樹上這個訊號都忽紅忽綠**（基準自己也翻過一次）。波動來源看得出來在**量測那一側**：
  同樣的 seed 與 duels，可判樣本數逐跑不同（`maskN` 10–12、`maskDropped.moved` 逐跑不同），
  也就是「這一跑抽到哪幾次閃紅」本身就在變。依 `02 §6.2`，**這個訊號目前不可信**，
  不得拿它宣告「本批讓 R2 退步」，也不得拿它宣告「沒退步」。
- **凍結檔 L10 寫的是「維持綠」**，而基準在 seed 1 就是紅的 ⇒ 這條閘門的原文在基準上就不成立，要重新校準。
