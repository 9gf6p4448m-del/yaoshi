日期：2026-10-01。使用者裁定：「照建議、以你的美感修正；遊戲只在橫式玩」。動作邏輯（事件→動作、錢／令牌時序）與凍結驗收 #B／#C 都沒改；直式 P 只維持機械檢查。未部署、未 push。

## 改了什麼（js/hand-motion.js 為主）
| 項 | 做法 |
|---|---|
| 袖子 | `dressColors`：腕後 0.08～0.40 dm 一圈舊棗紅袖口邊（線性 0.130/0.045/0.030，非黑），其後袖布轉暗並以 `alphaHash` 漸隱到 0.95 dm 完全消失；原本 z<−1.5 的黑袖全數隱去。四手共用一份複製幾何＋材質，仍是不透明那一趟，draw call 不變 |
| 縮放 | 0.35 → **0.335**。GLB 掌寬（Palm 主骨頂點 x 跨度）0.867 dm × 0.335 ＝ 0.290 ＝ 錢柱直徑 0.144 的 **2.02 倍**（目標 2～2.5 倍 ⇒ 縮放只能落在 0.332～0.415，所以「再降」只能降到這裡）。直式另乘 0.6 |
| 伸入深度 | 北席指尖 z ≤ 托盤北緣＋0.05；西／東 x 不越中線（留 0.06）；南／西／東指尖不伸進托盤前緣以內 0.02 以上（量測後追加：手指伸進去就擋在拍品腳前）。越線就沿進場方向退回，錢自己滑完剩下的距離，終點不變 |
| 推 | 由「掌根壓錢柱頂」改成「指尖抵住錢柱靠席位那側」：手指不再伸過錢柱、伸到拍品腳邊 |
| 拍 | 令牌飛行時手不上場（原本手舉著令牌從拍品正前方掃過）；令牌落地那一幀起手從席位那側伸進來，0.12 秒內掌心蓋上去→微顫→收。`ys:mark-slam` 仍由令牌發 |
| 收 | 錢柱遠側搆不到（伸入限制）時，整個動作改成指尖貼在錢柱靠席位那側領著錢回來 |
| 地板 | 托盤布面加一層低地板（布有皺褶）；空中令牌改成「懸空盒」：手可以從底下過，真的會撞才抬到上面 |
