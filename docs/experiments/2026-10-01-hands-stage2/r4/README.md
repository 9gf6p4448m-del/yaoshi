# 席位之手 2a 第四輪：一席推多格改排隊（使用者裁定方案甲）

日期：2026-10-02。未部署、未 push、不合 main。

## 做法
- `js/table-props.js`：手開著時（`handPaths`），一席出價若這一席別格還有錢在路上，這一格的錢排在後面：`delay＝前面剩餘時間＋QUEUE_GAP 0.06`、推送時間 `QUEUE_FLY 0.22`（第一格仍原速 0.42）。錢的終點不變；手關著時一字不差。`stackAt` 多回 `wait`／`fly`。
- `js/hand-motion.js`：每席多一個佇列。同席正在推別格、而這一格的錢在排隊 ⇒ 進佇列；一格錢落定就接下一格（重新抓那一格錢柱位置，等候間隔內從上一格結束處移過去），全部推完才收手。同格重複出價＝覆寫（佇列裡舊的那筆移除）；出價歸零／換夜／跳過＝清佇列。避讓信物與伸入界線照舊每格適用。
- 遊戲邏輯不等動畫（`index.html:3647`／`:6078` 只派事件；開標固定 `sleep` `:7323`／`:7327`）——trace-eq 對 `68d25790` equal:true。
