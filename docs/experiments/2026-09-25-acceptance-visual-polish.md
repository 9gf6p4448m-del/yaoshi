## 條件（V1–V4 全畫面×全模式；V5 不得變差）

**#1 斷行位置**：短標籤（按鈕字、座位名、角色名、數值列如「部隊 N 隻・攻 N・血 N」、tab）不得在詞中或數字與單位之間斷行。判定：元素渲染行數 >1 時，每個換行點落在允許的斷點（`・`、`｜`、空白、標點後，或 `<br>`／明確的 `.hcs` 類段落邊界）；按鈕字允許的例外必須逐一列名（例如刻意兩行的「蓋牌／開標」）。基準 `e29a753` 在 V1 必須判紅且含「袋子」鈕或底列座位名（使用者先前截圖可見「袋／子」「南・紅衣／婆婆」）。

**#2 文字不越框**：有可見框線或底色的容器，其內文字的外框不得超出容器外框（容差 1px）。基準已知 `#northPrev` 溢出 2–6px，須判紅。

**#3 字級下限**：可見文字計算字級 ≥ 10px（V1–V4）；低於者逐項列出，修到 ≥10px 或列入「可縮寫／裝飾」並寫理由（僅限非決策資訊）。

**#4 對比**：文字與其實際背景（取文字框下方像素的中位色，含半透明底疊 3D）對比 ≥ 4.5:1（<18px）／3:1（≥18px 或粗體 ≥14px）；未達者逐項列出並修。

**#5 觸控目標**：可點元素 ≥ 40×40 CSS px（Apple 建議 44，本遊戲密度高取 40）；未達者列出並修或寫理由。

**#6 同列對齊**：同一列並排的同類元件（左右座位卡、左右拍品卡、北列三格、底列按鈕群）上緣／下緣／高度差 ≤ 2px。

**#7 不回退**：text-fit 與 landscape-fit 治具重跑維持原通過數；`trace-eq` 對 `e29a753` 相等；全套改前通過案改後仍過；V1 關鍵畫面（首頁、選單、引言、出價、夜戰、局末、回顧）修前修後對照 contact sheet 由主對話目視。

**#8 送達**：bump 0.58.3（三處）、快轉推 main、Pages built、線上 curl 核對。使用者真機確認允許暫緩。
