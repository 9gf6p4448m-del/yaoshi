## 曾持有的記錄契約

對每局、每組、每席記錄首次完成的時點，以及曾完成者集合。只在實際遊戲狀態的材料變更後判定，不能用預覽、AI 估值、試算副本或 UI 首次演出當證據。需涵蓋拍賣得標、異事／道具移轉等所有實際袋子變更；同夜成套後失去仍屬曾持有，失而復得不重複計人，持有後淘汰也保留。

取得順序不得只在夜末抽樣：水陸允許同夜先補齊後攔截，連攜狀態可能在一個夜晚內改變。記錄不得消耗亂數、改變出價／結算次序或把對手袋子提供給策略。

未來 recorder 驗收必含：成套→同夜失去、失而復得、多副本、對手取得並贏局、持有者死亡、全局無人取得、預覽副本不計；開關記錄器的玩法 trace 逐位元組一致。原 runner 的 seat0 死亡即終止必須在量測名稱中保留，不冒稱四席完整續局。

## 正式執行前尚待定義

- 追連攜策略池：target-chaser-v1 是已具名探索策略；哪些策略參與正式判定、情報如何使用，必須在新樣本前固定。
- 千眼情報：明夜三件預告及上夜第二高標額須有合法策略輸入與實際消費的對照；目前盲策略的 0pp 不能量情報價值。
- 六之四：定義可達狀態／資訊集合、各席合法選項與出價格點、收益時間點與收益單位；窮舉須遍歷所聲稱範圍的所有組合。隨機模擬不是窮舉；固定幾組策略的勝率矩陣也不是全部玩家選項。

既有 analyzeEvent 只接受靜態、各席同選項的收益函式，且最多 2,000,000 個組合。跨夜連攜有預算、隱藏袋子、轉移、淘汰與未來資訊，不能把局部當夜測例的 PASS 解讀為整局放行。若縮小正式驗收聲稱範圍，依全域轉譯層「驗收條件凍結」規則須使用者明確裁定；本卷先完成可審核提案。

## 千眼合法情報策略契約

具名追件基準 target-chaser-v1 不改寫；另設尚待實作的情報候選與盲對照，其他 bidding／budget 邏輯一致。策略只獲得當時合法預告切片與上一夜揭盅時依法向該席提供的第二高標額；不能直接讀完整 nextMarket、對手袋子或尚未揭盅的本夜出價。無面人隱藏／不足兩筆回 null；揭盅記憶只影響下一次決策。

候選策略須先在固定局面證明：改變合法情報會改變後續出價，遮蔽後差異消失；早於揭盅不能利用第二高價。資訊提供路徑的零效果開關必須連 eyesSecondBid 的 id 判斷一起處理，不能只刪 CHAINS 欄位。策略與對照在大樣本前封存，測後不可按結果挑通過者。

## 六之四的可審查範圍提案

本卷建議維持原要求，先補觀測與情報策略，不將有限測例升格為完整六之四。要開始窮舉器前須完成下列工作單：

| 維度 | 完整跨夜檢查需定義 | 有限局面檢查的限制 |
|---|---|---|
| 起始狀態 | 三組分別有哪些可達袋子、壽命、回合與隱藏資訊集 | 指定少數快照只能證明該批快照 |
| 選項 | 各席全部合法標單、毒標目標、後續各夜條件決策 | 只列追／不追或 +2／不加價會漏掉其他標單 |
| 金額 | 原文允許合理離散網格，需列值與預算裁切後的合法集合 | 選點不全會漏支配關係，不能事後刪讓結果 FAIL 的點 |
| 收益 | 終局勝負／排名與平手規則、隨機分支如何取期望 | 當夜壽命不能代表明夜資訊與跨夜成套價值 |
| 組合數 | 各狀態至少為 ∏每席合法選項數；跨夜還需展開後繼與資訊策略 | 4席各2選項只有16種、各10選項就有10,000種；兩者不是同一命題 |

此為建模缺口，不是授權不足；目前沒有足夠依據報出完整枚舉數或工時。既有 analyzeEvent 把完全同值的選項也列為 dominant（strict:false），不得自行改為至少一處嚴格較好來增加通過率。若將來提議用有限局面檢查取代完整跨夜要求，必須先列具體狀態／網格／收益與排除範圍，再依凍結規則請使用者裁定。本輪不提出縮減，不需要為原要求重新取授權。
