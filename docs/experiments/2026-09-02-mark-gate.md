# 盯上宣告閘門（GAME_DESIGN §5.8）——實測與閘門改寫提案（2026-09-02，n=10000）

腳本：`tests/tools/mark-gate.mjs`（原版 G1~G4＋追加 G1′）、`mark-gate-fair.mjs`（G1′＋反事實活性 G2″）、`mark-explore*.mjs`（探索）。
桌型：混合＝預設角色分型（怯場 4／搶標 3／無視 3）；全怯場／全搶標＝把所有角色的 markReact 改成同一型。

## 1. 原版 G1（honest＝盯最高並標它／bluff＝盯次高、標最高／nomark）
    [G1 混合桌] honest 12.35%  bluff 5.10%  nomark 10.98%
      兩兩最大差 7.25pp ❌ >3
    [G1 全怯場桌] honest 29.01%  bluff 8.28%  nomark 15.06%   honest−bluff 20.73pp ✅ 誠實優
    [G1 全搶標桌] honest 10.32%  bluff 7.32%  nomark 13.73%   bluff−honest -3.00pp ❌
    
    [G2 活性] 混合桌 被盯件平均出價人數 1.70 vs 未盯 0.71
              全怯場桌 1.36 vs 0.98 ❌
              全搶標桌 1.86 vs 0.53 ✅ +10%
    
    [G3 稅] TAX=0: bluff−honest -1.70pp（不得 ≥+1）✅；TAX=1: -7.25pp（應 <0）✅
      bluff 每局平均繳稅 17.80（TAX=1）

**判讀**：純虛張（盯了卻不出價）在任何桌都最差，把稅設 0 仍輸誠實 1.7pp——「虛張」這個軸本身沒有回報，不是稅的問題。
原 G2 的「被盯件出價人數」有選樣偏差（被盯的多半是好貨，本來就多人搶），怯場桌量不出反應。

## 2. 對等對照 G1′（三策略同一套出價：主標 5 在戰力最高件＋側標 1 在次高件，只差盯哪件）＋反事實活性 G2″
    n=10000
    [G1′ 混合桌] mtop 24.41%  msec 24.78%  mnone 24.78%  最大差 0.37pp ✅
    [G1′ 全怯場桌] mtop 28.52%  msec 45.58%  mnone 22.89%  msec−mnone +22.69pp ✅
    [G1′ 全搶標桌] mtop 33.38%  msec 23.88%  mnone 34.56%  msec−mnone −10.68pp ✅
    [G2″ 我出價的件上、他人出價筆數／件]
      混合桌   mtop 1.128  msec 1.135  mnone 1.148
      全怯場桌 mtop 0.909  msec 0.889  mnone 1.045  mtop/mnone 0.870 ✅ −13%
      全搶標桌 mtop 1.197  msec 1.237  mnone 1.173  mtop/mnone 1.021 ❌（+2%，門檻 +10%）

**判讀**：「換桌會翻盤」成立，翻的軸是「盯主標／盯側標」：怯場桌盯側標把對手趕離你的 1 壽命側標＝白撿（+22.7pp），搶標桌同一招被圍剿（−10.7pp），
混合桌三法差 0.37pp＝沒有支配解。搶標型對主標的反應量不到（+2%）——主標本來就是大家要搶的；它的反應體現在側標上（勝率差 −10.7pp 即證據）。
探索過 MARK_CONTEST 6：搶標桌真人勝率飆到 45%（AI 互相加價自傷），不採。

## 3. 提案（待使用者裁定）
- G1 改寫為 G1′（對等出價下混合桌 ≤3pp、怯場桌與搶標桌「盯側標」效果正負相反各 ≥2pp）；原 G1 數據留檔。
- G2 改寫為 G2″（反事實：我出價的件上他人出價數，怯場桌 −10%）；搶標桌那半條以 G1′ 的勝率翻盤代替。
- 虛張稅 1 保留（防亂盯），文案拿掉「可以虛張」。
