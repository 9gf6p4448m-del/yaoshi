## 二、每張一句

- **`obsidian1.jpg`**：兩把黑曜石刀身。形是**細長的葉形（lanceolate）**——尖端收成一點，最寬處在靠尖端的三分之一處，往柄端緩緩收窄；長寬比約 4:1。整體近黑，但**高光不是柔和的面反光，而是一塊塊斷斷續續、邊緣銳利的亮斑與亮條**，那是打製剝片疤的玻璃斷口在反光。**外緣不是一條光滑的線**，是被壓剝出來的細密扇貝狀缺口。
- **`obsidian2.jpg`**：黑曜石石葉的斷面語言——刀身上有**幾道貫穿全長的筆直稜脊**，稜脊把刀面切成幾條長條形的平面，**其中一條稜上落著一道拉得很長的白色高光**。這一條就是「一看就是刀刃」的關鍵：**刀是有一條貫穿全長的直線的**，不是一團有機的塊。
- **`muntjac1.jpg`**：台灣山羌側面——**背脊在臀部最高，從臀往肩一路下滑**，肩（withers）低於臀，短頸再從低肩往前上斜出去，**頭幾乎與背線齊高或更低**。這個「拱背垂頭」的側影跟水鹿（`bow` 用的那隻，長頸近垂直、背線平）完全相反。腿相對身體偏短、下段近黑。體色是鏽紅褐，背脊更深。
- **`muntjac2.jpg`**：山羌的頭——**兩道長而多毛的角柄從兩眼之間往後上方斜出，柄上各有一道近黑的深色縱紋，兩道紋在額頭中央收攏成一個 V**；每根角柄頂端只有**一根短的、不分叉的骨白尖角**，往後翹。耳短、寬、橢圓，向兩側外張，耳廓內是亮的。眼是**大而深黑的圓眼**，眼前有一道很深的**腺裂**（一條斜的暗縫）。鼻端是一塊寬的近黑鼻鏡；嘴角可見一枚朝下的小獠牙。
- **`paiwan1.jpg`**：排灣族木雕盤——器身本身就是一個**帶尖端的葉形**。表面是**數圈同心的三角連紋帶**：一排三角朝上、緊接一排三角朝下，靠 V 形鑿溝刻出來，**沒有水平的牙根線**（所以讀成紋飾不是牙齒）。通體被鑿痕蓋滿、無一塊平滑；色是風化的深褐黑，鑿溝裡露出較淺的木色，**深底＋較亮的刻線**。
- **`knap1.jpg`**：打製手斧三視圖。正面是**大小不一的凹形剝片疤拼滿整面**，疤與疤之間是**銳利的稜**；**側視（左）證明它是一個薄透鏡**——柄端厚、往刃口急遽收薄。這一條決定刃臂必須是**板**不是**柱**。

### 為什麼物種選山羌（主對話決定，理由留檔）

1. **祭儀語境**：山羌是台灣原住民（布農、泰雅、排灣皆然）最普遍的狩獵獵物與祭儀肉品，「祭儀獸」用山羌比用外來獸種貼題。
2. **不撞車**：`bow` 已用水鹿（長頸近垂直、三叉大角、背線平），`boartusk` 已用山豬（外翻獠牙、swarm 橫排）。山羌的**拱背垂頭＋短不分叉尖角＋臉上 V 紋**與兩者側影完全分得開。
3. **體型對**：山羌小、緊、繃，配上一對佔全身高度近一半的黑曜石刃臂，比例落差就是 elite 要的「招牌部位大」。

## 三、一眼特徵清單（造型必做項；★＝側視也看得見）

> **本節寫下即凍結，動手後不得改**（凍結檔 `2026-09-04-acceptance-creature-batch.md`、`02 §2.1`）。M-A1 盲讀時 context-free 讀者**主動列出**的特徵須命中 **≥3 條**（出貨下限），**目標 5/5**；沒讀出的登記到 `docs/experiments/2026-09-04-creature-gaps.md`。

1. **★ 前肢從肘以下就是一片黑曜石薄刃：一邊是直的刃背、一邊是弧的刃口、尖端朝下插進地裡**（`obsidian1`＋`knap1`）。它是**一片板**——寬度是小腿的數倍、厚度是小腿的幾分之一；**不是爪**（沒有鉤、沒有分岔成多根）、**不是棒**（不是圓的）。左右各一片，兩片就是這隻的招牌剪影。
2. **★ 刃面被貝殼狀剝片疤鋪滿，且有一道貫穿全長的筆直亮線落在刃口上**（`obsidian2`＋`knap1`）。刃是**近黑的玻璃**：暗底上散著邊緣銳利的亮斑（剝片疤），加上**一條從根到尖不中斷的直線高光**——沒有那條直線，黑板子讀不出「刃」。
3. **★ 刃背上一列祖靈金的三角連紋帶**（`paiwan1`）：沿著刀刃那條**直**的背緣，排一列上下交錯相接的三角（百步蛇紋），金粉土黃色，**不留水平牙根線**（有牙根線就讀成牙齒）。這是本隻唯一的系別高飽和色帶，只落在刃背。
4. **★ 山羌的頭：兩道往後上斜出的長角柄在額頭收攏成深色 V，柄頂各一根短而不分叉的骨白尖角；短寬外張的圓耳；眼前一道腺裂**（`muntjac2`）。角要**短、單根、不分叉**（跟 `bow` 的三叉鹿角相反）。
5. **★ 自割的證據：胸口一道橫過去的發光割痕，口中透出同一種光**（「自割才靈」）；體態是山羌的**拱背垂頭**側影——臀高於肩、頭不高過背線（`muntjac1`）。割痕正落在攻擊時刃臂掃過的那條線上。

## 四、參照 → 造型的翻譯（anyCreature 沒有貼圖，全部翻成幾何）

| 特徵 | 幾何做法 |
|---|---|
| 刃臂本體 | 前肢鏈 `LFront` 只做到**腕**（短的帶毛上臂＋腕結），肘腕以下不給 volume；刃是掛在 `LFrontWrist` 上的 `fin`（`mirrored:true`，宿主名以 L 開頭是**肢體軸向關節**、L→R 換名找得到 `RFrontWrist`）。`fin` 只吃凸多邊形，葉形（直背＋弧刃＋尖端）本身是凸的，一片就夠 |
| 直背 vs 弧刃 | `points` 的一側寫成**共線的一串點**（直），另一側寫成外凸的弧；兩者在尖端交會。刃背朝後、刃口朝前 |
| 刃面剝片疤 | 刃板上再疊 4–6 片**更薄、更小、明度略不同**的黑曜石 `fin`（同一 udir/vdir 平面、thickness 較小、往外推 0.001–0.002），每片是不規則凸多邊形＝一塊剝片疤；疤與疤之間留下的縫就是稜 |
| 貫穿全長的直線高光 | 沿刃口內側一條**極窄的長條 `fin`**（材質 `blade_gleam`，冷亮灰 `#b9bcc4`），從根到尖不中斷；不用 emissive（會被 bloom 燒成一團） |
| 刃背三角連紋帶 | 沿直背緣排 7–9 片小三角 `fin`（材質 `zuli_gold`），**上下交錯相接**（一片尖朝刃口、下一片尖朝背外），相鄰兩片底邊相接不留水平線（`eye` 報告 ⑥-6） |
| 山羌角柄＋短尖角 | 每側一條 `curve`（材質 `hide_pedicle`，帶深色縱紋用另一片窄 `fin` 疊上去）從顱頂往後上，末端接一條更短的 `bone_tip` `curve`（`taper:true`）＝不分叉的短尖角 |
| 臉上深色 V | 兩片窄長 `fin`（材質 `face_stripe` 近黑中性灰）沿角柄前緣往下收到兩眼之間，兩片在額心幾乎相接＝V |
| 短寬外張圓耳 | 每側一片 `fin`（`ear_hide`）＋一片較小的亮內襯（`skull_bone`）＝暗框亮窩（`harden3B` ⑤-4） |
| 眼前腺裂 | 眼前一道窄的近黑 `fin`（`face_stripe`），斜的 |
| 胸口發光割痕 | 一片細長透鏡形 `fin`（`glow_cut`）橫過胸前，上下各壓一片近黑的「傷口唇」`fin`（`hide_cut`）讓它讀成裂開的口不是畫上去的線；再從割痕縫裡竄出 4–6 條長短不一的細 `curve`（`glow_cut`）＝漏出來的靈光（`thunder` ⑥-4：有東西竄出來才讀成活的） |
| 口中發光 | 下顎與上顎之間留出口縫，縫裡塞一片 `mouth_glow` `fin`；口角掛兩根朝下的小獠牙（`bone_tip`） |
| 拱背垂頭 | 脊椎關節 y：`Rump` 最高，`Barrel`→`Chest`→`Withers` 逐級下降；頸從低肩往前上斜、頭頂不高過臀頂太多 |
| 木雕鑿刻做工 | `build:"rigid"`＋所有 volume `faceted:true`＋profile `exp` ≥4.5＋`smooth_angle` 26 |
