# A3 S6 滿編構圖小卷（凍結 #10）

凍結：[2026-09-18-acceptance-a3-experience-slice.md #10](../2026-09-18-acceptance-a3-experience-slice.md)。起點 main `de33149`（v0.57.31）。
目標＝A2 結案卷 [#4 滿編指認補做 0/6](../2026-09-17-a2-closeout/duel-readers/score.json) 的三件：拼板舟／福壽綿長／魔神仔紅帽。
改法**只限**兩條：8v8 同型單位錯位排列（站位／朝向）、描邊改該尊主色；不動模型、ART_BIBLE 色票、演出時長。

## 讀者材料量到的真因（改碼前）

- 8v8 每側 **2 寬 × 4 深**（`FIG.perRow: 2`、`rowsMax: 4`），站位「小前大後」（`duel-figures.js` baseOrder），同型三隻體型相同 ⇒ 連續佔前兩排，第三隻（第 1 排 k0）正好站在第 0 排 k0 的正後方；鏡頭俯角 24°，前後排的框幾乎重疊。
- 橫向沒有空間：每排的可用寬度 `[lo+fIn, hiOut−fOut]` 在 8v8 本來就被塞滿（r1 量到同排兩隻只多分開 0.02 世界單位）。
- 描邊色只吃陣營（`creature-figures.js outlineColorOf`）：紅帽是陰氣 ⇒ 青綠描邊蓋在紅斗笠上。

## 治具

讀出來的事：
- 構圖題在拼板舟／紅帽已解（遮擋率全 ≤30%；紅帽兩位都數到 2–3 隻在正確位置；opus 在福壽把四隻數出來了）。
- 拼板舟敗在**名冊裡敵方本來就有一艘船（王船）**，兩位都把它算進去，判準把「指到右半（敵方）」記為未命中；兩位在左半也都只數到 1 艘（三艘在前線一排但小、暗）。
- 福壽敗在**身分**：腹部長明燈碗被讀成香爐（A2 結案卷「低多邊形讀不出身分」同族題）。
- 這兩個原因都不在凍結 #10 允許的兩條改法（站位／朝向、描邊主色）之內。第 2 輪（凍結上限 2 輪）**未用**：可提案 `dupTurnBias −12`（船與龜多露側面剪影）三件全部重讀，是否要燒這一輪交使用者裁定。
