## 發布前尚缺的平衡定義

[既有 L1 提案 §2.3](../../proposals/2026-09-10-roadmap-v2-review.md) 要求每組六之四窮舉、追連鎖對 splitter −8～+5pp、持有者優勢 +3～+10pp（n≥10000）。這些仍有效，本段未量、未通過。

追查 [傳說 H1/H9 原凍結](../2026-09-10-acceptance-legend-v3.md) 與 `tests/tools/legend-gate.mjs`：H1 分母是每策略 10000 局；H9 是正常／零效果各自「有持有者局」的條件勝率差，不是持有者對非持有者直接比較。連鎖還需具體定義追組合策略與「曾湊齊／局末持有」的持有者口徑，不能任挑有利的分母。

六之四原為離散異事選項的收益窮舉；L1 提案將它延伸到被動連鎖，尚未定義購買行動網格、局面全集及收益時距。現有 analyzeEvent 不能直接證明跨夜購買策略不存在支配；舊共鳴 R1/R3 也不能替代。正式紙紮已取消戰力，用 sum(p) 當等戰力配對的歷史工具不適用。

後續建議先完成 L1c 共用補件查詢的 UI／AI，再將追組合策略、H9 分母與窮舉範圍具體化並凍結；數值門檻不動。若需改驗收範圍，依原制度另裁，不能將本段工程測試充作平衡證據。
