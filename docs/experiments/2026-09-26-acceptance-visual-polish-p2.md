## 條件

**#1 無系統 emoji**：V1–V5 × 全模式的可見文字（含 `::before/::after` content、按鈕、tooltip 內文）以 Unicode Extended_Pictographic 掃描，命中 0。例外只限手繪頭像 `<img>`（不是文字）與盯章 SVG。基準 14ac1f2 必須判紅（出價畫面有 😊🔊）。

**#2 拍品窄籤（出價／盯上）**：預設狀態下完整拍品卡面板不可見；每件拍品以邊緣窄籤呈現，籤上顯示**全名**（不得截斷或省略號，#1–#6 第一階段判準照用）、高 ≥40px、點擊區 ≥40×40；每籤有一條系色條，其計算色等於該拍品所屬陣營的色 token（四系：祖靈、香火、陰氣、詛咒各一，治具逐籤比對）；點籤可展開原拍品卡的全部資訊（逐項等價，missing 0）。

**#3 揭盅結果窄條**：結果窄條的下緣與 `#south`（底列）上緣距離 0–4px、不重疊底列；結果條內資訊與原結果卡逐項等價（missing 0）；字級不小於原卡（15／12px）。

**#4 祖靈色可辨**：祖靈色條計算色與金線色（`--gold` 或實際框線色）的 CIEDE2000 ΔE ≥ 20；四系色條兩兩 ΔE ≥ 20。基準值與改後值都要列。

**#5 北列摘要**：摘要字計算字級 ≥11px，且對實際背景對比 ≥4.5:1（量法同第一階段 #4）。第一階段北列 (a)–(d) 仍全過。

**#6 字體分工**：標題、卡名、數字類元素的計算 font-family 首選為同一明體系；內文為黑體系。所用字型在 iOS Safari 須可取得（已載入的 web font 或 iOS 內建），不得只在 Windows 生效——回報寫明 iOS 實際會用哪個字。不新增 cdnjs／jsdelivr／Google Fonts 以外的外部資源。

**#7 首頁甲**：
- (a) 標題區塊矩形中心 x < 視窗寬 40%、y > 視窗高 50%（V1–V5）；三顆入口鈕與版本號可見、點擊區 ≥40×40。
- (b) 首頁相機（位置／FOV／target）與牌桌相機不同，且**進入牌桌後相機參數與 14ac1f2 逐值相同**（`north-camera-probe.mjs` 同法量）。
- (c) 聚光只在首頁存在：牌桌狀態下場景燈光清單與參數跟 14ac1f2 逐值相同。
- (d) 版本字串照舊可見（使用者靠首頁那行判斷是否上線）。

**#8 其餘畫面只換皮**：夜戰、選角、夜行錄選單、引言卡、本局回顧、局末，各主要容器矩形與 14ac1f2 相差 ≤2px（V1）；#1 同樣適用。
