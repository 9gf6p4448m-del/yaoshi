## 2. 修訂1：遮擋閘門（hands-occlusion ≤10%，來源 5a794080／r2 README「遮擋最大值 <10%」自我驗收）

**原標準錯在哪／為什麼現在才知道：** 閘門是第二輪為「手不擋拍品資訊」設的，隱含假設是「手蓋住拍品＝壞」。使用者 10-08 看三欄對照圖後明確選「全放寬」，理由正是「要有真的蓋在上面的感覺」——拍令牌時手蓋在令牌（以及令牌旁的拍品）上是被要求的意圖，原標準沒有把「令牌拍下」當成例外。這點是看到全放寬的實圖後才有的需求，所以現在才知道。

**新標準（最小改動，不是把 10% 調成 30%）：**
- 閘門值仍是 **≤10%**，所有情境、所有時段不變；
- 唯一豁免：「令牌拍下接觸窗口」內**那一席**的手。窗口＝該格 `ys:mark-slam` 事件起，到 `ENTRY_MAX＋TREMBLE_MS＋HOLD_MS`（現為 0.66 s＝40 步）為止（取自 `HAND.SLAM`，不寫死）；
- 窗口內的遮擋量**另列**輸出（`occlMaxInSlamWindow`），不進閘門；同一取樣若同時有別席的手在窗口外，該手仍計閘門。
- 治具驗紅：把窗口縮成 0 → 閘門紅（exit 1，`occlusion_le_10pct:false`）。

## 4. 實作過程中查到的事（避免下一個人再踩）

- **ENTRY_HALF 0.45**：手長且常斜向進場（西／東手在 z 向佔 0.46 m），margin 0.25–0.40 在 L 仍有 17–745 個首幀頂點在布面內，0.45 起 L／P 全 0（量測：`hand-reach-probe --layout=L|P`）。

- 進場最快速度：單幀頂點位移最大 0.33 m（≈20 m/s 峰值），平均約 8 m/s（覆審 F6 更正）。**手感未驗證，【試玩必調】**：`ENTRY_MAX／ENTRY_HALF／ENTRY_V`。
- 拍令牌的手掌蓋上令牌時間：0.12 s → 0.20–0.40 s（接觸窗口＋停留總長也同步變長）。
