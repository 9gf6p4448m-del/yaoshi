## ⑧ 本卷實測到的新引擎陷阱（已同步寫進兩隻 spec 的 `_traps`）

`wangchuan.json` `_traps` ⑦–⑪：

- **⑦ volume 的 profile 每列 `[t, a, b]` 的 t 是「沿關節折線的弧長比例」，不是關節序號。** `compile.js:113-131` 先對關節折線做弧長表再每 `ring_step` 重取樣。本檔七個關節的弧長 t 是 0 / 0.216 / 0.338 / 0.500 / 0.623 / 0.766 / 1.0，跟原檔寫的 0.12 / 0.29 / 0.47 **對不上**——要改哪一段的粗細先算弧長，不要照關節數心算。
- **⑧ `frame:"up"` 的臥姿主鏈下，profile 的 `a` 是左右寬（Z）、`b` 是上下高（Y）。** 與 `ashcharm` ⑧（直立主鏈時 a=Z、b=X）是同一條規則的兩個面：a 一律是 U 軸（水平寬）、b 一律是 W 軸。要把甲板線壓低是改 **b**，改 a 只會把船變窄。本卷 r9 第一版照 (X,Z) 心算，整個破洞挖錯方向。
- **⑨ `part_attachment` 量的是「頂點到最近 ring 圓心的距離 − 該 ring 的最大半徑」，取所有頂點的最小值**（`checks.js:303-320`）。兩個推論：(a) 只要有**一個**頂點靠近鏈心就過，肋骨／火舌的尖端愛伸多遠都行；(b) 把 volume 收細之後，原本貼在舊表面上的板子會**整批**浮空——用同一條公式在 Python 端寫預測器一次抓出全部（本卷抓出 8 片），不要靠 cli 的 BLOCK 一條一條試。
- **⑩ ★★ 在暗色船殼上，黑色的鋸齒／尖角一律被讀成「火焰或羽毛裝飾」。** r11／r13 四位逐字：「橙紅色羽毛狀／火焰狀裝飾物」「橘紅色鋸齒狀火焰／羽毛裝飾」「黑紅相間的尖刺／裝飾物」「黑色鋸齒狀裝飾物（類似鰭或羽飾）」。要讓斷口讀成「折斷」，靠的是**斷面露出的淺色新木**＋**與本體同材質、角度歪掉的鬆脫板**，不是更多黑色尖角。這條可直接套到後面所有做「破損／殘缺」的隻。
- **⑪ 火舌若伸出本體輪廓之外，就變成剪影上的裝飾鰭**；要它讀成「從破口冒出的火」，長度必須收在破口內、方向偏垂直。

`ashcharm.json` `_traps` ⑯–⑱：

- **⑯ ★★ 黃底上的黑色幾何字符，只要對稱又規則，就會被讀成「電路符號／插頭／鑰匙孔」。** r12 的「通貫頂橫蓋＋三根等長直勾」兩位逐字如此。改法三件同時做：(a) 拿掉通貫的頂橫蓋，三勾改成**斜的、長短不一**、外兩勾各帶一支內鉤腳 (b) 中段短筆左右錯開、上下不等距、每筆略帶傾角（四邊形不要用正矩形）(c) 直軸做成上寬下窄的梯形。規則性一降下來就從「符號」變回「字」。
- **⑰ 矩形黃紙片＝電路板／旗牌。** 符紙下緣收成尖劍尾的五邊形（`[[-w,-0.52h],[0,-h],[w,-0.52h],[w,h],[-w,h]]`，嚴格凸、fin 吃得下）之後才有「紙符」的形。
- **⑱ 符片放大時不能只放大半高、把中心留在原處**——掛符竹骨在符片上緣，中心不動會讓上緣越過竹骨變成「插在桿子上」。要沿該片自己的 `vdir` 反向平移 `(h_old − h_new)` 把上緣釘住往下長；傾斜的翼尖符片（`vdir` 有大 y 分量）用世界 Y 平移會直接扯離竹骨，實測 6 條 `part_attachment` BLOCK。
