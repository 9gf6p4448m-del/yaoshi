## 二、每張一句

- **`lion1.jpg`**：整隻是一塊灰石鑿出來的，**方、硬、塊面分明**——沒有一處是滑順的圓；獅頭幾乎和胸一樣寬，坐在一座上大下小的方形石座上，頸上繫著現代人綁的紅綢帶、胸前一大朵紅綵球，爪下踩著一隻小獅。
- **`lion2.jpg`**：把「石獅到底長怎樣」講死的一張——**整個後腦與頸背覆滿一顆顆凸起的螺旋捲**，每一顆都是一個往內收的漩渦；耳朵是往後掠的薄片，吻部皺起、上唇翻開露出獠牙，下顎還有一叢同樣的螺旋鬍鬚捲。
- **`flag1.jpg`**：旗本身是**一片細長的三角**，斜插在天上、尖端遠高過所有人頭；靠桿那一側是直邊，另一長邊整條掛滿流蘇穗，夜裡被燈打成一整條**金橘色的火**——這就是簡報說的「旗面捲著火」的實景來源。

## 三、一眼特徵清單（造型必做項；★＝側視也看得見）

1. **★ 螺旋鬈鬃**：頭頂、後腦、頸背滿佈一顆顆**凸起的螺旋捲毛球**，大小相近、成排並列（`lion2` 全滿、`lion1` 眉上與耳周一排）。這是石獅最不可能被誤讀的一件。
2. **★ 後掠／垂片大耳**：耳朵是一片薄板，從頭側往後（`lion2`）或往下（`lion1`）掛出去，不是圓耳。
3. **闊嘴露獠牙＋寬扁翻鼻＋厚眉脊壓著的深陷眼**：吻短而寬、鼻頭寬扁上翻、上唇掀開露出成對獠牙；眼睛嵌在一道厚眉脊下（`lion1` 的眼是鑿出來的圓珠，但被眉脊壓成一條斜縫的陰影）。
4. **胸前紅綢＋綵球**：頸繫紅綢帶斜過胸口，胸前結成一顆大紅球（`lion1` 實拍，是廟方年年繫上去的，屬於「石獅在廟裡的真實樣子」）；爪下另有繡球或幼獅。
5. **★ 蹲坐的方形塊體＋方形石座**：後腿折收、前腿兩根短柱直撐、身體壓低成一塊方的量體，底下是一座上大下小的**方形石座**——輪廓全是直線與硬轉折，沒有圓潤過渡。
6. **★ 令旗＝細長斜三角＋長柄＋長邊流蘇**：靠桿的一側是直邊，另一長邊整條掛滿穗子；旗桿是一根筆直長桿，**明顯超出旗尖繼續往上**；配色是金橘＋紅。

> 以上 6 條就是本隻的必做清單。M-A1 盲讀時 context-free 讀者列出的特徵必須命中 ≥3 條。

## 四、參照 → 造型的翻譯（anyCreature 沒有貼圖，全部翻成幾何）

| 特徵 | 幾何做法 |
|---|---|
| 螺旋鬈鬃 | 十餘顆 `curve`（3 段、`coil` 讓它捲）沿頭頂／後腦／頸背排兩三列，材質 `mane_curl` |
| 後掠垂耳 | 一對 `fin` 薄板，`conform:false`，從頭側往後下方掛 |
| 獠牙／翻鼻／厚眉 | `curve` 獠牙（上下各一對）、`fin` 寬扁鼻楔、`fin` 厚眉脊板壓在 `eye` 之上 |
| 深陷發光眼 | `eye` 小球（size 0.030，不放大——放大就會被讀成可愛）＋眉脊板遮住上緣 |
| 紅綢＋綵球 | 兩片斜過胸口的 `fin`（`sash`，硃紅）＋胸前一顆短 `curve` 球結（`sash_knot`） |
| 蹲坐方塊＋石座 | 主鏈**垂直站立**＋`frame:"up"`、斷面 `exp` 4.6–5.2（方箱）、`build:"rigid"`＋`faceted`（石雕＝構造物，引擎允許）；底部一圈外擴的方座 |
| 細長斜三角旗 | 一片大 `fin`（`flag_cloth`），三角形三頂點在旗桿平面上；底角埋進背部＝「背插」 |
| 旗桿超出旗尖 | 一條長 `curve`（`pole_wood`）＋頂端 `gold_trim` 槍尖 |
| 長邊流蘇／火 | 五條 `glow_flag` `curve` 沿旗的斜邊往外捲（`rise`＋`coil`）＝簡報的「旗面捲著火」 |
| 香灰 | 顱頂一條不發光的灰白 `colors.arcs` 帶（ART_BIBLE §5「香灰＝肩頂一層灰白 arc 帶」） |

## 五、刻意不照抄的地方（與「不可愛」守則的取捨）

`lion1` 的獅臉在真實比例下是**圓的、憨的**（那是台灣民間石獅的可親性格）。使用者裁定「不可愛、精緻、大作感」優先，所以：
- 眼**不放大**、加厚眉脊壓住上緣（真實石獅的眼確實嵌在眉脊下，這是加強不是竄改）；
- 全身斷面用 `exp` 4.6–5.2 的方箱＋`build:"rigid"` 全平面，取 `lion1` 的「鑿出來的塊面」而不是照片被風化磨圓的表面；
- 嘴取 `lion2` 的**掀唇露獠牙**而不是 `lion1` 的微笑口。
ART_BIBLE §0.5-4：「圖騰化、風格化是在特徵之上做，不是取代特徵」——上面三條都還在特徵清單之內，沒有一條把清單裡的項目換掉。
