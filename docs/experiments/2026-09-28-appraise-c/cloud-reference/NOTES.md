## 正式實作的主要風險
- 甲：①直書 12～15px（能力文字分欄會斷在句中，例如巴冷那句拆成 3 欄）②燒符是逐像素 ImageData（約 0.8 秒）＋全螢幕 2D 壓暗／光柱每幀重畫，吃手機 CPU ③加一盞 SpotLight 會讓所有材質的 shader 重編，要開局預熱 ④鑑賞時藏起其餘拍品＝互動上的改變，要使用者裁定。
- 乙：①每幀多兩趟繪製＋法寶畫兩次（draw 約 +35%），手機 GPU 風險最高 ②寬體型法寶（虎爺印）轉到側面時會超出鏡面、壓到八卦環 ③鏡子在 WebGL 層，HUD 是 DOM 會浮在鏡子上 ⇒ 鑑賞時 HUD 必須收暗（甲乙示意都已收到 6%）④題字直接寫在暗底上，12px 那兩欄在手機上偏小。
