# L1 三組連鎖：試玩候選凍結 v0.1

基準 5b73313，2026-09-21 使用者：「繼續開工到完成需要試玩段落」。沿用已批准 D2；本卷目標是可重現、可直接遊玩的三組候選。正式發布的六之四／n≥10000 門檻不撤銷、不宣稱通過；試玩入口獨立於正式站。

## 共通

- 規則可查三組配方；自己補件提示與生效狀態只在當前玩家的私有操作畫面，交棒或開標共享畫面不露其他人的配方持有列表。
- UI 與 AI 都讀 chainsCompletedBy。AI 候選估值每完成一組 +2，已生效組合及重複副本不加；只讀自己的材料，不新增讀對手袋子的連鎖決策。
- 材料不消耗、缺件失效、同組不疊加。首次湊齊在本人私有畫面顯示一次雙材料合攏＋同心方陣及連鎖名稱；不在對手共享畫面公布。失而復得不重播；新局重置。減少動態設定下使用靜態結果，不強制閃光或晃動。
- 新規則加入後 trace 可不同；清空 CHAINS 時仍需對 de471a2 seeds1–20 exact equal。不得為達成等價更動舊規則。

## 千眼神算

- eye＋bell；preview 取最大值 3。揭盅的「第二高」定義為有效 entries 的原始標額降序第二筆，並列也算一筆；不足兩筆無數值。
- 現版 bidPills 已公開所有原始標額，千眼的第二高提示目前是整理既有公開資訊，不冒稱獨占新情報，不縮減別人的既有資訊。
- 無面人 showEntries=false 優先，不准繞過；不得洩漏尚未開標的標額或標書型態。私有提示於本人的袋子／後續操作畫面讀已公開上一夜資料；熱座交棒遮罩下不顯示。
- 新增 onReveal context 如有必要，只做 additive 欄位；不可擴張全域 onMarketDraw。

## 雙虎滅煞

- tiger＋nail；buildArmy 僅替換袋中各第一件有效材料，插在兩者較早的位置，其他副本仍正常出兵。材料與非部隊被動保留，缺件立刻恢復原部隊。
- 試玩數值由 Astra 指定：一尊 elite、攻9／血8、香火系，模型鍵 twinTiger。原兩尊各攻7／血4；單尊全額第二目標濺射提供橫掃，另忽略目標隊伍 armor 減傷（撕甲），不忽略送王船 absorb。此為待平衡候選，不以舊提案示例當作已驗證數值。
- 新 TRAITS 組合欄位描述橫掃＋撕甲，不在引擎按名稱寫專例。戰報、袋子總計與融合隊伍預覽使用同一 buildArmy；單件卡仍顯示單件原部隊。
- 新金斑黑虎資產採既有虎爺參照、紙紮幾何與黑金配色，新增獨立資產鍵，不能覆寫原虎。造型明確為長身四足虎、條紋、尖牙、武將護肩；本輪候選截圖供實際試玩簽收，不宣稱新美術盲讀驗收通過。

## 試玩前必過

1. RED→GREEN checkpoints；有效／失效／重複／材料非消耗、AI實際行為差異、預告最大值、第二高並列與隱藏優先、熱座私有資訊、融合來源與副本、撕甲不免吸收皆有行為測試。
2. 受影響測試通過；至少兩個本輪語意突變能被測試抓到；新增核心函式 source-range 覆蓋≥80%，列分母。
3. 844×390、1280×720 開圖，390×844 維持轉橫提示；零新增 pageerror，無文字水平溢出。每組可在試玩入口直接重現（注入起始材料／拍品，清楚標為練習），另有正常隨機局。
4. 雙虎實際戰場有新模型、沒有粉紅缺材質或資產404；恢復缺件時回到原單位，預覽與戰場一致。既有演出時長與鏡頭不變。
5. Astra 最終 code review 與視覺核對。試玩前列明尚缺正式平衡／美術盲讀驗收，不把玩家試玩回覆代寫為通過。

## 試玩後再作的判斷

請使用者確認：補件提示是否可理解；三組觸發能否看懂；雙虎是否像黑金虎將、單尊替換是否清楚；是否有操作卡住或資訊過多。A3 原六局研究仍暫緩，不拿本卷試玩混充。
