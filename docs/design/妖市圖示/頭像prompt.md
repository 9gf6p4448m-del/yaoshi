# 頭像 prompt（9 個角色，背景全部綠底）

做法：每個角色先在「新對話」生健康版 → 在同一對話用【蒼白編輯】做蒼白版 → 回到健康版那張圖，用【瀕死編輯】做瀕死版。
存檔名：角色_健康 / 角色_蒼白 / 角色_瀕死（貼給 Claude 時寫清楚是哪個角色哪個狀態）。

---

## 【蒼白編輯】（附上健康版圖，同一對話貼）

Same character, same pose, same composition, same clothing and background exactly. Change only: the skin turns sickly pale grey, the clothing looks slightly faded, the eyes look tired and weak.

## 【瀕死編輯】（附上健康版圖，同一對話貼）

Same character, same pose, same composition, same clothing and background exactly. Change only: the skin turns a cold corpse blue-green, the clothing becomes noticeably desaturated and dull, the eyes become dead and glassy with a blank flat look.
