## 壹、 四大核心技術借鑒與在地化映射

### 1. 死亡碎裂與紙骨崩解演算法 (Shatter Geometry Engine)
* **技術借鑒**：ShatterGeometry.js + ObjectPool.js。
* **妖市落地情境**：Tier 2 妖怪減員／力竭暴斃（F06）演出。
* **工程與美術規範**：
  - **拒絕生硬淡出**：妖怪被擊潰時，禁止單純調整 Material opacity 淡出。
  - **紙紮碎裂機制**：衝擊拍（
eact 起點）瞬間，依預設或動態切分的三角面網格，由頂點著色器沿模型法線與衝擊方向快速爆散為 16~32 片帶折痕的「紙紮碎屑」。
  - **燒蝕收勢**：碎片在 200ms 內由邊緣向中心觸發 urn 著色器（金邊炭化），化為灰燼消散，整體時間精準收斂在 	1 或 	2 的 settle 區間內。

### 2. 法寶顯靈與貼桌印陣 (Rune Decals & Table Marks)
* **技術借鑒**：ShardRuneMaterial.js + GroundDecals.js。
* **妖市落地情境**：虎爺印砸下、水鬼浮標投擲、陰陽錢落桌時的「貼桌陣」。
* **工程與美術規範**：
  - **程序化同心符陣**：以單一 Quad 貼於深紅老檜木桌面上，透過手寫片段著色器極座標轉換（Polar Coordinates）繪製旋轉八卦、道教符頭與金線邊框，省去高解析度貼圖載入。
  - **衝擊漲開（Expansion & Stamp）**：印信落桌瞬間，法陣自中心向外激波膨脹，印文由墨色（ink）瞬轉高溫微光（hot），隨後平滑降溫凝固為桌面焦印。

### 3. 水面擾動與幽氣扭曲 (Water Ripple & Mist Distortion)
* **技術借鑒**：OceanWaterMaterial.js + DistortionShader.js。
* **妖市落地情境**：解決待辦項「buoy 腳下水面 VFX」與陰氣系法寶蓄勢。
* **工程與美術規範**：
  - **輕量浮標水面**：水鬼浮標（buoy）腳下採用低多邊形圓形網格，頂點著色器疊加兩組正弦波與簡易噪聲模擬水面顛簸，片段著色器混合墨水與苔綠深度漸層，完全避免重型流體模擬。
  - **鬼氣扭曲熱浪**：利用全螢幕後處理的輕量化頂點位移通道，在法寶重擊或陰氣爆發周圍產生 100ms 的空間微扭曲，強化視覺重音。

### 4. 招式即時調參工作流 (In-game Preset Pipeline)
* **技術借鑒**：Editor.js + settings.js 單一真相來源。
* **妖市落地情境**：加速 js/trait-fx/ 27 套妖怪招式的微調與驗收。
* **工程規範**：
  - 在對決原型頁面（?proto=）接入輕量參數橋接，支援美術即時微調衝擊拍時長、粒子散落半徑、法陣亮度，並可一鍵導出為 JSON 寫回代碼，避免反覆手動重寫數值。

## 貳、 三大剛性紅線與效能鐵律 (Non-Negotiables)

### 1. 嚴禁西幻霓虹色，全數回歸民俗色票 (Palette Integrity)
所有著色器之色彩計算，必須嚴格綁定 js/trait-fx/vocab.js 的 FX_PAL，嚴禁使用任何高飽和度電競藍紫光：
* **香火系**：硃砂血紅 (#b91c1c)、鎏金香火 (#f59e0b)、純白淨火。
* **祖靈系**：沉穩土褐 (#78350f)、幽玄靛藍 (#1e3a8a)、石板冷灰。
* **陰氣系**：深潭苔綠 (#064e3b)、深邃濕黑 (#0f172a)、雄黃濁水。

### 2. 嚴格對齊三拍節奏（不得拖慢對決節奏）
所有引進之著色器動畫，生命週期必須嚴格吻合：
* **短招 (t1)**：總長度 ≤ 300ms，衝擊拍鎖定在 208ms，收勢在 277~300ms 必須完全切淨。
* **中招 (t2)**：總長度 ≤ 900ms，衝擊拍鎖定在 560~623ms。
* **大招 (t3)**：≤ 1.5s，僅限三尊顯靈等最高規格演出。

### 3. 手機網頁與真機 60 FPS 預算
* **粒子預算**：單招粒子總數 ≤ 90 顆（如虎爺印範本：硃紅 90 顆 + 紙錢 45 顆）。
* **零運行時 GC Alloc**：對決期間嚴禁 
ew THREE.Mesh 或 
ew THREE.ShaderMaterial，所有法陣、碎屑、貼花均需在進入對決時完成對象池預熱。
* **後處理降級**：Distortion 通道預設對低階行動裝置（如舊款 iPhone）保持可降級開關，確保幀率絕不跌破 60 FPS。
