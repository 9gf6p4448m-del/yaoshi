# 妖市（Yaoshi）——用壽命競標的策略對戰遊戲

深夜妖怪市集的暗標會：壽命既是錢包也是血條。競標祖靈／香火／陰氣三系法寶、把詛咒品塞給別人、自動結算戰，活到天亮者勝。
單檔網頁（`index.html`，手機直式，PWA），線上版：https://9gf6p4448m-del.github.io/yaoshi/

## 給協作者（含 AI）的閱讀順序

1. `docs/GAME_DESIGN.md` — 設計文件（權威版）：三支柱、核心循環、深度設計（§5，含 §5.8 盯上宣告）、四層內容架構、完整內容規格、優勢策略窮舉閘門、changelog。
2. `docs/IMPLEMENTATION_GUIDE.md` — 實作手冊：資料表驅動架構（ABILITIES／ROLES／WISHES／EVENTS／NIGHTRULES）、hook 契約、怎麼加內容、強制檢查清單（§7）、§11 各版接手須知。
3. `docs/ARCH_SPEC.md` — 架構規格與待辦總表（§9 末尾）。
4. `docs/experiments/` — 每一批的驗收凍結檔與平衡實驗報告（n≥10000），設計裁定的依據都在這裡。
5. `index.html` — 全部程式（引擎＋UI，約 3,500 行）。`?sim=1` 開平衡模擬器。

## 設計原則（改動前先讀）

- 數值全集中在 `CFG`，標【試玩必調】的都可一句話改；改規則骨架走設計文件的裁定流程。
- 新內容上線前必過閘門：異事走優勢策略窮舉（§六之四）、心願走條件勝率、機制走 n≥10000 的策略對照；閘門不過改設計不改數字。
- 種子化亂數：`trace(seeds)` 逐位元組比對是等價驗證的標準做法（手冊 §7）。
