A 盲聽指認（凍結 #4）

8 題，每題播一支音、四選一或「都不像」。種子固定，順序由種子決定；重播次數會記進 JSON。門檻 ≥6/8 且每支 ≥1/2。

B 既有 12 支逐支留／換／關（凍結 #5）

逐支聽，選「留／換／關」，要換的請寫一句想怎麼換。

C 一夜序列連播（凍結 #6②）

落籌×3 → 封標 → 開市鑼 → 揭盅×3 → 受咒 → 受擊 → 天明。播完勾「哪兩聲糊在一起」；門檻 0 對。

D 四支新音甲／乙挑選（計畫 §0）

每個事件聽甲、乙，挑一個，寫一句為什麼（原話會落檔）。挑定後才做盲聽。
